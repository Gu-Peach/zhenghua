# ADR-0006：Supervisor 短期记忆与阶段 0 验收

日期：2026-10-10。状态：accepted。

## 决策与边界

此前 `conversation_id` 只有关联用途，HTTP 回合未加载历史，Run/checkpoint 不构成对话记忆。本轮提供有界、按 conversation/user 隔离的进程内短期记忆，保留近期用户/助手消息、附件引用、检测结果、待确认事项和最新任务引用。每轮将上下文传给 Supervisor LLM，用户可仅输入“确认”或修正类型。会话绑定操作者，重复 turn_id 返回原结果，不能再次调用模型或工具。

新增 DETECT_PROFILE 意图，与完整提取意图区分。检测入口由 Supervisor 选择，服务端只读取 PDF 第一物理页；所有检测结果（含高置信结果）在该入口均等待用户确认。确认只完成类型选择，不进入 Stage 1/2/3，不创建业务结果版本。完整提取原链路保留。

阶段 0 附件通过受内部服务鉴权保护的 HTTP 上传接口登记，保存于 Agent 私有 runtime，会话限定为类型识别。无业务项目时不创建项目/线表，不允许把这类附件传给完整提取 Worker。运行状态及 Supabase repository 不替代会话记忆。

验收脚本位于 `services/agent/agent_test/0.detection_test`，只读取输入 PDF、调用 HTTP、展示事件和接收终端输入；禁止导入 agent_service、调用 VLM/Supabase 或编排检测工具。真实推理由正在运行的 Agent 服务完成。流式回合展示简短计划、工具调度及结果；不依赖前端 Mock。

短期记忆仅对同一服务进程有效，不支持服务重启或多实例共享；长期记忆尚未实现。记录最多 12 个近期回合，单个进程最多保留 256 个会话。部署验收使用单实例，未来可通过持久化会话 repository 扩展，不把本轮写成长期记忆已完成。

## 执行顺序

2. 服务端短期记忆、附件、检测/确认与事件接口（完成）。
3. 纯 HTTP 终端客户端和 Fake API 集成测试（完成）。
4. 类型/契约检查、文档与交付（完成）。
