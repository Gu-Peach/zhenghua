# ADR-0012：共享且直接可用的规则资源库

日期：2026-10-12。状态：accepted（用户明确要求取消草稿模式）。

## 决策

- 用户创建/上传的规则资源库为所有已登录用户共享；元数据和三阶段 Prompt/Few-shot 都可读，不再按创建者隐藏。
- 用户上传或创建、且未停用的合法规则包直接可用于提取，旧 draft 标记迁移为 active；UI 不展示草稿状态。
- 每个 Profile 新任务默认使用最近登记的未停用版本；显式冻结 checksum 的历史任务继续使用原包。删除仍是创建者确认后的 retired 停用，不重新启用被删除包。
- 历史数据库状态列及不可变资源包保留以兼容审计/旧任务，不通过重写历史 migration 或覆盖 Bucket 对象抹除版本。
- Improvement 生成的 `profile_candidates` 及其隔离资源不是规则库条目，仍需原有用户授权、评测与确认；不因共享读取自动触发文件编辑或上线候选。
- 共享的是规则资源，不是项目 PDF、连接、反馈和模型 Trace；项目数据权限不变。Bucket 仍私有，通过已鉴权 Server 签名访问，匿名读取不开放。
- ABB 使用独立 adapter/policy，不复用 ZH 起点白名单、端子映射、引用规则或电流推算。

## 实施与风险

新增 migration 替换 authenticated SELECT 策略、把非候选 draft 升为 active，并允许同一 Profile 多个可追溯版本共存。后续收紧策略明确：`candidate_id is null` 的规则库包向所有登录用户共享，隔离候选仍只对创建者/审核者可见。Agent 为新任务选择最新 active 包，UI 去掉草稿标识，删除权限仍属于创建者；候选包不进入规则库。新增合法包不会改变已冻结任务；未知适配器或损坏资源仍明确失败，不能以“库里存在”代替资源校验。

默认测试使用 Fake VLM，不调用真实模型。ABB 真实图纸字段准确率由后续人工验收确定，不把执行支持宣称为识别质量已验证。
