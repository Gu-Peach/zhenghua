# ADR-0013 用户确认后直接发布规则修改

日期：2026-10-13。状态：Accepted（用户明确变更此前评测门禁要求）。

## 决策

当前产品串行人工验收，不再把模型回归评测、二次审核或 canary 作为规则修改前置条件。归因展示问题片段与建议，用户明确确认后，Worker 构建隔离资源包并直接启用。拒绝/未确认不得写生效规则。保留包校验、路径/可执行身份限制、来源授权、版本冲突检查和审计；这些不是模型评测。

使用新不可变版本保存修改，不原地覆盖历史 Bucket 对象。数据库原子更新候选及包状态并记录明确的 `confirmed_publish` 审计，不伪造 gate_passed 或评测报告。旧项目不自动重绑。已有未发布候选可通过确认接口/同一聊天确认直接启用，不重复模型构建。

## 执行步骤

1. 已完成：发布 repository/RPC 与确认后 Worker，复用旧包及确定性候选 ID 防止重复构建。
2. 已完成：Supervisor pending 状态与既有候选确认、HTTP 确认接口、前端/终端接续同步。
3. 已完成：Fake 回归、真实本地 DB 事务回滚验证、类型/构建与文档收尾。验证范围见实施记录。

旧评测代码及数据暂留兼容已入队任务，不再开放新评测启动入口，也不主动停止用户的已有任务。发布不表示已经证明准确率无回归；取消门禁可能使有缺陷的建议生效，这是用户选择的取舍。三阶段提取与线表结果确定性校验不变。
