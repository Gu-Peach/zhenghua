# ADR-0014：Stage 2 逐页闭环提取

状态：Accepted（用户于 2026-10-13 授权实施）。替代新运行的独立 Stage 3 调度；历史阶段枚举/资源兼容标识可保留用于读取历史记录。

## 决策

Stage 1 仍完成全图索引。Stage 2 是可单独调用的 LangGraph：扫描本页起点连接 → 根据引用定向补全（来源图＋目标图）→ 合并/校验 → 保存完成页。保存成功后才进入下一页。删除独立 Stage 3 Agent、子图和全局补全阶段；跨页能力作为 Stage 2 内部步骤，保持强类型任务边界。

ZH 由放线标记、实际路径和相对端子的箭头判定起点，不用 XA/XD 白名单筛选或交换方向。接收端不创建记录；无箭头由模型根据本页证据判断，证据不足保留复核。实际端子排标识优先；未标注时按已知端子映射分类，无映射/冲突则留空，不虚构业务代号。

跨页只处理已发现的连接，不全量提取目标页，不递归扩张。未知/缺失目标、回指来源的循环、目标端点不清晰均保留 null 和复核原因，继续下一连接/页面。配置、权限、数据库写入失败仍报错，不能伪装为正常空结果。

## 持久化与兼容

初扫与内部补全的模型输出保存在 PAGE_SCAN 模型缓存，不是页完成标志；完整页结果单独写 PAGE_SCAN 的 `pdf-page:<n>` StageItem。重启优先复用已完成页，跳过其模型调用。页内稳定 ID/运行键保证写入幂等，不新增复杂全局连接合并。

冻结输入增加 `workflow=page_extraction_v2`；新运行阶段为 RENDER → PAGE_CLASSIFICATION → PAGE_SCAN → VALIDATION。SQL 前驱校验按冻结输入选择，旧输入保持原阶段历史，仅供读取；新代码不恢复旧三阶段 run，应创建新 run。需要新 migration，不修改已应用迁移，本轮不执行。现有最终业务结果版本由 Server 原子提交；逐页持久化是完成页结构化事实，当前工作台尚不承诺逐页显示业务版本。

纠错复用 Stage 2 内部补全与来源图，不再调用独立 Stage 3；既有任务类型/持久资源名称保留为兼容标识，不能把远端旧包自动改写或重绑已有项目。

## 验证

按用户要求仅离线冒烟，验证非 XD 起点、实际端子/分类、页间调用顺序、双图、未知/循环空值、完成页保存失败停止推进和恢复。真实模型、数据库迁移执行与准确率均另行验收，不声称已通过。
