# ADR-0016：ZH放线段的直接端子与后处理分类

状态：Accepted（用户2026-10-14明确要求）。修订ADR-0014及ZH2.0.1的端点/分类口径；仅本地ZH2.0.2，不发布或重绑旧任务。

## 决策

2026-10-16本地ZH2.1.1跨页读取修订：补全上下文v2不再提供来源端子/坐标/方向文字，state原值保留；目标回指可在任意边界且朝外，终点归属按任务，不重新定向。接口与接点针脚分别读取后组成完整端子，母排按原文读取。目标不可定位时，只有同一来源页PDF原文中工作区/对象匹配且地址唯一、目标存在时才核对恢复，模型raw与程序source_index_raw分别保留；不得无依据改页号。见[设计](../service/agent/zh-cross-page-reading-fix-plan.md)。

2026-10-15定向补全修订（本地ZH2.1.0）：来源初扫结果保存在state，补全只发送目标图与结构化来源事实，按来源业务工作区/页码/Object Loc回指、原理号及可见signal_name匹配。初扫方法不变，仅补充可选信号名输出；页级字段及原始引用保留。起点端子、坐标、原理号、方向与已有电流保持；不唯一匹配置空待复核。Profile输入模式默认双图，本地ZH选择target_only，ABB/XMZ不切换。详细契约见[设计](../service/agent/zh-target-only-completion-plan.md)，替代ZH内部补全必须提供双图的旧约定。

2026-10-15电流读取修订（本地ZH2.0.5）：端点与坐标确定后，可独立沿该相线实际导线跨过端子寻找对应断路器的电流标注，仅用于电流证据，不改变端点/坐标/方向或借用相邻回路。Ir优先；没有Ir时允许单一明确In/Ie，Ie:(0.7-1)*160A直接读取原文明确标出的160A，basis=Ie，不做系数运算，不用Set替代。003C01的FC11/FC12为160A、FC13为80A，分别关联XA:8～13和XD10:13～15；N/PE、控制/通信/光纤仍不填电流，不扩散到整个unit。该条替代旧版对Ie系数表达式的一律排除。

2026-10-15坐标及样例修订（本地ZH2.0.4）：每个实际端点可带terminal_coordinates={x,y,pdf_page_number}；x/y为端子符号/连接点中心相对整张原图的归一化坐标，左上角(0,0)、右下角(1,1)，不得填写端子文字、斜杠或跨页箭头位置。物理页为该端所在图片的PDF页，不是业务页或引用页。未知坐标为null，补全来源元件不得改变来源端子坐标。最终WireRecord保留start_terminal_coordinates/end_terminal_coordinates，当前本地标准XLSX在原12列后追加两列JSON坐标，不修改1641.xlsx。

初扫接收负例替换为003.C/1完整放线段案例，原有两组跨页案例改为003.C/1到080.C/10相线、到004.C/1中性线。只移除ZH当前样例目录中不再使用的图/expected/task，不影响其他Profile、原图目录或旧运行产物。沿用用户确认的元件优先级：目标回指中的+01F11.1优先于来源端附近+01F10，不以旧标准表覆盖图中引用。

2026-10-14元件字段口径补充（本地ZH2.0.3）：device用于起/终点元件列，读取对应端的元件标识，常见为+01F...等对象位置标识；X/XD/XA/XH排号和原理号不作为device。端子附近明确的对象位置优先于同处器件代号；同页按附近标识→该端所在页Object Loc，跨页按对应线路引用中的对象标识→附近→该端所在页Object Loc。出页引用的+对象属于对端，目标页对应线路回指的+对象属于来源端，不串用两端页眉。没有对象位置但有明确实际元件标识时可读取该标识；所有依据缺失才置空。location继续保存所属对象位置，terminal_board/terminal保留实际端子身份。

初扫跨页end仍为null，将可读的对端对象标识保存于references.target_object。内部补全新增可选source_component结构（device/location/basis），仅用于根据目标页回指完善来源元件与对象位置；冻结起点端子、原理号与方向，不接受完整start重写。旧模型响应不带此结构时保持原行为，ABB/XMZ提示词与策略不变。

围绕每个放线标记，沿其所在导线向两侧读到直接连接的端子。遇到端子即停止，不穿过端子继续到PLC或其他设备。同排附近明确的X/XD/XA/XH标识与数字组合为完整端子（例如XD3:109）；局部位置/设备描述按图读取。模型根据箭头或实际接线判断起终点，不用前缀决定方向。

2026-10-14用户进一步明确初扫顺序：先定位实际放线标记，以标记为追踪起点沿导线两侧延伸，读到最近端子或跨页箭头后再判断方向；原理号与端子文字只用于读取和匹配信息，不能代替放线标记成为搜索起点。方向只使用该放线段上的箭头，不借用隔着端子或设备的其他段箭头；跨页出线保留本页端子和引用、终点留空。无箭头时仍按原有本页接线/未知值规则处理，不增加XA/XD固定方向约束。

用户确认M23包含XD3:17→XD3:1和XD3:2～8→XD3:109～115八个放线段。上游跨页接收段和下游PLC连接不会取代这些段的端点。

初扫/补全Prompt删除按特定页列出的反例自查、预先排除特定功能地址、重复身份/路径强制检查及电流以外的额外硬推断。仅保留字段含义、实际导线/箭头、分支、引用、不确定值和JSON结构。电流原有约束保留。

terminal_board记录图中实际排号/接口；terminal为完整实际端子；terminal_code仅记录实际接口标识。terminal_strip是导出业务分类，不由VLM读图或猜测，模型返回的分类值忽略。

后处理根据明确实际端子前缀（完整terminal优先，再看terminal_board/device）映射：XA/XD10～12→X1；XD21→X21，XD23→X23；XD22→X22，XD24→X24；XD3/XD5→X3；XD4→X4；XH→X5。普通X3/X5/X9接口不映射成业务分类。两端均无上述映射则为空。起点映射优先，起点无映射时取终点；两端不同也不让模型仲裁。未知XD1/XD0等不补造类别。

已完整读取的terminal优先于其他身份字段；裸数字可以由明确的terminal_board或设备排号补齐。不能把设备K2、TA1等当作端子排前缀。保留同排两端的位置，避免多个柜中的XD3混同。
