# ADR-0016：ZH放线段的直接端子与后处理分类

状态：Accepted（用户2026-10-14明确要求）。修订ADR-0014及ZH2.0.1的端点/分类口径；仅本地ZH2.0.2，不发布或重绑旧任务。

## 决策

围绕每个放线标记，沿其所在导线向两侧读到直接连接的端子。遇到端子即停止，不穿过端子继续到PLC或其他设备。同排附近明确的X/XD/XA/XH标识与数字组合为完整端子（例如XD3:109）；局部位置/设备描述按图读取。模型根据箭头或实际接线判断起终点，不用前缀决定方向。

2026-10-14用户进一步明确初扫顺序：先定位实际放线标记，以标记为追踪起点沿导线两侧延伸，读到最近端子或跨页箭头后再判断方向；原理号与端子文字只用于读取和匹配信息，不能代替放线标记成为搜索起点。方向只使用该放线段上的箭头，不借用隔着端子或设备的其他段箭头；跨页出线保留本页端子和引用、终点留空。无箭头时仍按原有本页接线/未知值规则处理，不增加XA/XD固定方向约束。

用户确认M23包含XD3:17→XD3:1和XD3:2～8→XD3:109～115八个放线段。上游跨页接收段和下游PLC连接不会取代这些段的端点。

初扫/补全Prompt删除按特定页列出的反例自查、预先排除特定功能地址、重复身份/路径强制检查及电流以外的额外硬推断。仅保留字段含义、实际导线/箭头、分支、引用、不确定值和JSON结构。电流原有约束保留。

terminal_board记录图中实际排号/接口；terminal为完整实际端子；terminal_code仅记录实际接口标识。terminal_strip是导出业务分类，不由VLM读图或猜测，模型返回的分类值忽略。

后处理根据明确实际端子前缀（完整terminal优先，再看terminal_board/device）映射：XA/XD10～12→X1；XD21→X21，XD23→X23；XD22→X22，XD24→X24；XD3/XD5→X3；XD4→X4；XH→X5。普通X3/X5/X9接口不映射成业务分类。两端均无上述映射则为空。起点映射优先，起点无映射时取终点；两端不同也不让模型仲裁。未知XD1/XD0等不补造类别。

已完整读取的terminal优先于其他身份字段；裸数字可以由明确的terminal_board或设备排号补齐。不能把设备K2、TA1等当作端子排前缀。保留同排两端的位置，避免多个柜中的XD3混同。
