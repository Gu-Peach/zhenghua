# ADR-0019：统一提取主表与端子坐标

2026-10-15，Accepted for local implementation。用户明确要求ABB、XMZ全部对齐ZH当前输出。

主表使用同一14列契约：页码、原理号、端子排、起点元件、起点描述、起点端子、终点元件、终点描述、终点端子、电流、色标、备注、起点端子坐标、终点端子坐标。公共Graph的table.json/table.xlsx/分组表、直接记录XLSX主表与本地拆页脚本复用同一表头和行映射；不再分别维护11/14列。色标保留为空，元件优先device、其次location，描述只用name，端子照规范化后的实际terminal，备注使用remark，不把source_note调试文本自动混入业务备注。完整位置、读取依据和中间端点继续保留在记录JSON/原始提取诊断页。

各模板独立的放线、元件、端子排和原理号语义保持，不能用ZH柜号规则覆盖ABB设备。图纸页标签沿用当前可逆索引显示。固定业务导入模板文件保持自身格式，不能以主表改造破坏外部模板。

共享端点坐标契约为terminal_coordinates={x,y,pdf_page_number}，x/y为整图左上原点、0到1归一化的实际端子符号/接点中心，缩放不改变坐标系；页号由实际输入绑定。初扫同页两端、跨页补全目标分别读图，起点坐标冻结；不可定位或未知针脚时为空，不按编号排列或外部表补造。所有模板的Schema/调用说明均包含此契约，ABB/XMZ提示词及真实图expected同步，本地版本分别1.1.4和0.1.2。

现有11列产物不是最新契约，不静默覆盖；旧结果缺失坐标不能凭空补齐。本轮只改本地源码/资源，静态检查，不执行测试、真实模型、数据库或规则发布。用户新运行后生成统一格式；已有Web/API字段对象不改，本次没有业务数据库或外部REST Schema迁移。
