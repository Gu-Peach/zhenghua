# ADR-0021：先独立开发能力，清理旧总调度

日期：2026-10-16。状态：方向已获用户授权，具体删除范围待确认。自动审批拒绝92文件批量删除及入口改写，当前仅完成设计与依赖审阅，代码尚未删除或停用。

当前Server/Web已按ADR-0020采用三表数据管理，AI入口未接入。旧Supervisor、纠错、自完善、评测和旧业务表写入链路不再作为有效运行入口；本决策允许删除这些旧实现，不再保留一个能误启用旧链路的控制面。

保留独立 `src.agent.extraction_agent` 的Stage 1/2模型操作、页/文档Graph、规则、Few-shot、CLI和其必需共享依赖。用户正在修改的提取文件不覆盖。`explain_agent` 和 `profile_agent` 目前只建立职责文档，不伪造可用实现或新增监听端口；后续独立开发、验证后再组合主Deep Agent。

拟将共享8100入口精简为探活、本地只读Profile查询和能力声明；移除旧任务/导入/Proposal/规则发布/Supervisor API及自动Worker。Stage持久化适配和仍被提取依赖的数据类型可以保留，但不声称已适配新三表。未来正式写库须单独实现三表契约。

清理独占测试与已失效的终端验收命令；保留提取、资源、基础工具和当前Server默认回归。数据库、Storage、历史运行产物、迁移、前端本轮不改，不停止或重启已有进程。
