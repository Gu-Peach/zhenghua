# ADR 0022：上传即提取与增量结果发布

状态：已采纳，2026-10-16，用户确认完整范围；代码及离线验收完成，本地迁移已部署；实际模型联调待验证。

PDF保存成功后，业务API在现有agent_runs中创建simple_extraction_v1任务。独立提取Worker领取带租约的任务，复用分类及Stage 2页工作流；不依赖旧Supervisor，也不恢复Stage 3。旧API和Worker保留。

图片先上传私有Storage，再提交图纸索引；初扫、每组跨页补全及页最终校验分别提交，同一连接使用稳定ID更新。提交RPC同时更新三张业务表中的项目索引/线表、阶段产物及事件。浏览器通过鉴权的Server SSE获知变化，再读取业务快照，断线重连以快照恢复。数据库始终为业务事实来源。

所有模型结果和最终页快照按run、stage、item缓存；租约令牌防止旧Worker覆盖新Worker。重试复用任务及原有Profile快照。处理中的结果暂不允许人工编辑；失败保留已提交数据。未知端点置空，程序计算复核原因；等待补全不等于最终人工复核。

新增RPC仅service_role可执行；项目所有者和归档检查在事务内执行。SSE和重试入口由业务API验证JWT与项目所有权。生产Worker可独立启动，无需为每个Agent另开端口。

验收以Fake VLM、契约、数据库及前端测试为主；本次不运行付费模型评测。迁移只新增函数，不删除历史表/接口，不执行待确认的旧Agent清理。
