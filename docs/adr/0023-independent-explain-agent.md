# ADR-0023：独立行级解释Agent

2026-10-16，用户授权在Explain Agent目录开发，使用LangGraph。沿用仓库已存在的explain_agent目录（用户消息中的explain_agentt视为同一能力）。

## 边界

Explain只读当前三表和项目图纸索引，通过repository按可信调用者的用户ID、project_id、connection_id加载上下文。用户身份由宿主鉴权层提供，模型/请求正文不得指定actor。每轮重查权限与行版本；没有权限、批次/版本冲突时不调用模型。缺失图纸/证据保留明确缺口，不重新提取或补造历史推理。

Graph：读取授权记录 → 整理图纸与证据 → 根据记录和短期对话生成公开回答 → 返回结构化来源及回答。图片返回短期签名地址供UI展示；本轮语言模型不接收图片、不声称视觉复核。规则元数据优先用该行evidence.profile冻结版本，不把当前规则当作历史事实。

多轮以用户+conversation_id隔离，固定目标项目/连接；每轮刷新上下文，行/批次更新时清除旧历史，版本明确不匹配返回冲突。只保存有界进程内短期历史，重启不恢复。模型只处理事实包和文字，不获得数据库写入工具。

新增模块内Python入口与可挂载HTTP/SSE router，由宿主显式注入身份依赖；当前不挂接旧Supervisor/8100装配，不新增监听端口，也不改前端。以后可由8000鉴权接口或主Agent调用同一个模块。SSE只发结构化来源、公开回答delta、最终结果/安全错误，不流出Graph内部state或签名URL到模型提示。

不新增表/迁移/业务写入；不执行待确认92文件清理。验证使用Fake VLM、MockTransport和本地TestClient，不调用真实模型或数据库。
