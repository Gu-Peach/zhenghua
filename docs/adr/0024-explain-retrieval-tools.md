# ADR-0024：Explain Agent 的只读检索工具

2026-10-16，按用户要求扩展 ADR-0023 的固定行解释。保留单行调用，同时允许前端传入页码或多个精确条件作为会话初始查询。模型可调用 `search_connections`，在当前授权项目和批次中检索线表与关联原页/跨页图纸，不能指定用户、项目、SQL或存储路径。

Graph先获取前端选择的初始上下文，随后模型决定调用工具或回答，工具结果回到模型，可重复调用。规划轮使用原生function calling，最终公开回答流式输出。为保持已有提取调用兼容，共享ModelGateway仅增加可选tools/tool_calls字段，旧请求不发送工具参数。

查询字段使用Pydantic约束，并由repository转换为PostgREST精确eq条件（组合条件为AND）；页码明确区分来源业务页、目标业务页和物理页。默认查询来源页；查询以该页为终点的连接使用目标页字段。默认批次来自当前项目active_batch_id；行入口兼容已选行批次。分页使用稳定顺序并返回has_more/next_offset，模型须继续分页才能声称整页覆盖。一次最多8次工具调用，达到限制时只解释已取得资料并标注范围。

复用单行证据提取与Storage校验，整页按记录聚合图纸并按项目/物理页去重；仅通过唯一索引确认的引用目标图可以附加展示，未确认的目标标明引用候选，不能视为已证实终点。签名URL只返回界面，不传语言模型。新增view_drawings，模型可读取已检索物理页的图像：先验证身份/项目/私有桶/命名空间，再下载并转内联图像，单次最多4页、每轮6页，每张限制1536px最长边和100万像素。看图不重新提取，不将当前视觉判断伪装成历史过程；visual_pages说明实际提供了哪些图。查询记录和证据路径作为公开结构化结果，不输出内部思考。

每轮重查权限、初始条件及上一轮检索条件，已查看图像重新读取并比较摘要，结果变化使历史失效；重放缓存也必须重查相关检索，防止动态工具结果过期。coverage按精确条件汇总连续分页，模型提前结束也明确未覆盖范围。无表结构变更、无数据库业务写入、不接旧Supervisor、不新增端口。本轮不改前端，提供可挂载HTTP/SSE及同步OpenAPI契约供后续接入。
