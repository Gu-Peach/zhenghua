# ADR-0025：独立来源解释浮窗接入

2026-10-16，用户要求前端接入Explain Agent，不复用已有主对话框。

表格每行悬停/键盘聚焦显示来源解释按钮；页码组首增加整页解释按钮。行入口携带行ID/批次/行版本，页入口携带业务页及PDF物理页（消除重号）。浮窗打开后自动发起解释，支持取消、追问、失败重试、关闭与项目切换清理；触屏入口始终可见。

浏览器仅请求8000，Server校验Supabase JWT和当前三表项目权限后转发8100共享宿主。Agent由内部令牌验证可信服务并接收Server提供的用户身份，再独立校验数据权限；浏览器不能指定actor。挂载到现有src.extraction_main，不新增服务端口，不启用旧Supervisor。生产内部令牌缺失时拒绝，开发环境允许未配置令牌的本地调用。

Explain事件新增tool_started/tool_completed/tool_failed，涵盖初始检索与模型工具调用；仅公开校验后参数、结构化结果与安全错误，不公开推理或图像base64。UI用淡色可展开工具行展示结果和原页/跨页图纸，最终流式解释获取链路；“正在分析”只是执行状态，不伪造内部思考。完成前可流式显示公开说明。

Agent生成公共JSON Schema快照，Server使用独立Pydantic输入适配器，并用契约测试保证一致；Server OpenAPI引用同一事件Schema，Web由此生成类型。Server不导入Agent执行代码，仍保持进程边界。

不更改提取规则或数据库Schema，不写业务数据；本轮默认Fake模型/HTTP夹具测试及截图，真实付费模型不自动调用。保留现有AI入口，新的浮窗独立挂载。
