# ADR 0026：独立 Profile Agent 与规则草稿工具

2026-10-17，状态：已实施并离线验收；界面与正式发布后接。用户确认先交付独立Agent核心，界面与正式发布后接。

Profile Agent根据用户的图纸样例、提取描述生成Profile草稿，或读取指定Profile及其样例诊断重复错误。共用实际端子识别、证据约束和固定输出Schema；放线标记、分区/页码映射、命名、跨页模式进入强类型模板字段。不能把ZH品牌识别或其案例答案当成新模板的事实。

通过独立LangGraph中的模型/工具循环执行读取模板、规则及样例图、生成修改建议和草稿编辑。建议包含精确文件变更与依据；建议未确认不能执行写工具。用户明确给出修改指令时由可信调用参数授权草稿编辑，模型不能自行声明已获批准。诊断区分规则问题、案例问题、模型偏离、混合与证据不足，不凭单次输出证明“每次如此”。

草稿由本地repository按可信用户隔离持久化，原Profile只读，修订使用乐观版本/摘要、幂等操作及before/after审计。修改采用不可变修订目录和原子HEAD切换；用户拒绝、过期建议、越权或不安全路径不得改变草稿。工具不执行Python/命令，不改提取模型、共享Schema或生产Profile。附件由可信接口写入草稿，仅图片可进入视觉输入。

新建草稿以统一模板构建，不自动复制ZH图像及Expected作为新标准案例。期望答案采用提取阶段Pydantic Schema；AI建议的答案保留待用户确认，不假称人工确认。包输出检查所有引用、案例阶段与实际图像、输出契约、checksum、必填差异字段及现有adapter兼容性。涉及新确定性解析器时明确阻断可用包输出，不由Prompt伪装为已支持。

交付包括独立Python接口、CLI及可注册APIRouter，便于之后接共享8100宿主与主Agent工具。当前不改Explain/共享模型网关/宿主，不增加数据库表或新端口，不自动发布、重绑项目、运行提取或付费评测。包输出是文件产物，正式启用由未来业务Server提交。
