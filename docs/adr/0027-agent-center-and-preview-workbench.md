# ADR-0027：智能体中心与图纸校验工作台

2026-10-17，用户要求前端信息架构调整。本轮不改变后端、提取规则或数据库契约，不启停用户服务。

用户菜单新增“智能体中心”保护路由/agents，展示Extraction、Explain、Profile三张卡片。状态来自现有capabilities的“能力已接入/未接入”，不冒充运行时在线；独立Agent版本接口缺失时明确未提供。Extraction内使用现有规则引用与资源浏览功能，展示名为zh_extraction等Skill，保留真实Profile key/ID/版本/校验摘要。界面更名不声称已转换成运行时Skill自动加载。

项目导航仅“线表工作区”和“图纸预览”。默认线表占满中间区域，不显示底部预览；移除线号显示列，数据仍保留。预览模式保持同一线表范围/分页/编辑/Explain会话，表格只展示页码、原理号、起点端子、终点端子、电流，右侧上原页/下目标页。窄屏使用垂直响应布局，避免横向挤压。

点击起点或终点选择连接；跳转跨页终点时读取原页/目标页并显示下方目标图，同页连接在原图标出两端。标记使用各端{x,y,pdf_page_number}且必须与当前图片物理页一致，非法或缺失不猜位置，给出未标注说明。图像和标记在同一个缩放容器中，保持归一化坐标。选择其他范围、分页或数据更新时不沿用旧行标记；异步返回按查询身份隔离。

能力状态/版本缺口、原图加载/链接失效、权限失败、无坐标、同页/跨页及过时响应通过离线测试验证。Agent中心和旧规则浏览组件复用，保留旧目录组件文件但不再作为项目导航入口。
