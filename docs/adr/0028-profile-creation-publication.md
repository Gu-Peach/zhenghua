# ADR 0028：三步规则创建与手动发布

2026-10-17，状态：代码与离线验收完成；迁移/实际服务未部署，真实模型质量待验收。

规则配置入口位于智能体中心 Profile Agent。静态模板固定 classification、scan、completion 三块及实际提取 Pydantic 输出 Schema。PDF 项目名取文件名，不由模型推断。三步分别生成可编辑规则说明和 Expected 候选，用户确认后原子保存规则、图片案例、Expected 和 manifest；模型生成不等于人工确认。

候选在隔离草稿的不可变修订内保存，绑定来源修订/阶段依赖；刷新可以继续。修改前序确认内容使依赖阶段失效。初扫跨页终点留空，补全按已确认初扫连接建立任务；用户上传来源及目标图，单任务有限图片，来源身份冻结。缺目标/不明确结果保持空值。

用户点击发布后 Server 经可信内部身份获取校验通过的规则包，先写私有 Storage 内容寻址不可变对象，再登记 extraction_profiles 引用。同 key/version 不得覆盖不同内容，所有者/幂等/并发由数据库 RPC 保障；已有本地引用继续兼容。目录、资源预览、PDF 选用和 Worker 同时支持 storage:// 规则包，不恢复旧业务表。包完整性、用户确认与适配器能力是发布门槛，不自动执行付费评测或额外审核。

Agent 草稿仍由独立 Agent repository 管理；正式规则元数据是数据库事实，ZIP 为不可变资源。无新增 Agent 端口，沿用浏览器→8000 JWT→8100 内部鉴权。业务 API 使用同步生成的 Pydantic/TS 契约。
