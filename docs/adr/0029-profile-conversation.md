# ADR 0029：通过对话逐步创建提取规则

2026-10-17，状态：代码与离线验收完成，真实模型质量待用户核对。承接ADR-0028的草稿、阶段确认和发布边界。

新界面以聊天接收规则名称、文字和图片。规则标识默认生成唯一值，显示于草稿摘要。LangGraph每轮读取当前草稿、已确认阶段及对话，由模型判断缺少的信息并追问。只有图像和阶段信息充分时，调用既有ProfileWizard生成规则/Expected候选；信息不足只保存对话。模型不拥有确认或发布权限。

分类阶段展示工作区/页号读取方式；初扫展示放线标记、起终点及引用，跨页终点保持空值；补全复用已确认初扫原图和引用，由模型读取用户上传目标页地址，按目标索引调用原补全机制。返回的是面向用户的图纸证据说明，不展示内部思维过程。用户可以在聊天中纠正，或展开表格编辑后明确确认，随后保存既有规则与Expected文件。

对话及幂等回执与候选/阶段确认在同一草稿修订中保存，按用户隔离，版本冲突拒绝覆盖；历史有限展示但不更改来源身份。原三步接口和表单组件保留以便渐进迁移。新增对话GET与SSE POST，经8000鉴权代理到8100，不新增端口/业务表，不改变发布RPC。Schema从Agent生成Server及OpenAPI/TS。

验收使用Fake VLM、Mock代理和浏览器夹具，覆盖追问、上传、修正、逐阶段确认、恢复、失败/取消/版本冲突及权限。真实模型效果由用户后续验收。
