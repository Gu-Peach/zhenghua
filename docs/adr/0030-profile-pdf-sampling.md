# ADR 0030：规则分类阶段从PDF随机取两页

2026-10-17，代码与离线验收完成；真实模型质量待用户核对。承接ADR-0029。

Profile创建聊天第一阶段可上传PDF。专用工具在内存打开PDF，读取页数后均匀随机无放回选择两页，只渲染抽中页；不足两页时只取实际一页并明确说明。页面按物理页升序展示，但随机选择不受排序影响。原PDF和未抽中页均不写入缓存、业务库或Storage，因而没有未抽中图纸需要事后清理。选中图作为长期草稿/案例证据保留，登记文件摘要、物理页号与附件ID。

抽样渲染全部成功后，repository在单次草稿修订内保存两图及抽样回执；重试同一request_id必须返回同一两页，内容冲突拒绝，不重复抽样。无效/加密PDF或渲染失败不创建草稿附件。新PDF属于分类依据变更，清除旧三阶段候选/确认，保留历史修订与对话。默认50MiB，生成图最长边2048，格式沿用PNG。

Agent对照两页推测分页方式；候选保留共享规则及每页独立Expected/公开证据，物理页不冒充业务页。确认仍由用户操作，封面/空白等样本不足时追问，不凭两页保证全册规则正确。后续初扫/补全只使用用户主动上传的原图和跨页图，不自动采用PDF里的其他页。
