# ADR 0033：Explain 线表修改工具与确认提交

2026-10-18 用户纠正后的当前约定：记录所属页/工作区/来源与关联跨页索引保持不变，只交换端点元件、描述、端子及坐标对象（含坐标自己的PDF页号）。此前迁页约定撤回；10项独立SQL、70项Agent、25项编辑/预览浏览器通过，新迁移已部署且指定4行恢复006C01/006.C，端点及坐标不变。详见[归属修正](../service/server/explain-swap-origin-correction.md)。

2026-10-18删行补充：用户要求删除线表不保留业务记录副本。删除仍物理移除，清除该行在项目管理审计/旧请求中的前后值及包含该行的修改方案；仅保留不含端点值的幂等删除回执，其他行编辑继续审计。新迁移只替换函数，不批量清理已有项目历史。用户明确工作区时Agent主动查询，不重复询问“当前页还是工作区”。此前跟随新起点页迁移记录的实现已撤回，见上方当前约定。[历史排障](../service/server/changelog/2026-10-18-explain-delete-relocation.md)。

2026-10-18，状态：代码/离线验收完成，本项目本地迁移已部署，8000/8100待用户重载。用户要求Explain支持工作区端子去XD前缀、指定原理号起终点调换等数据修改，并确认默认整组端点（元件、描述、端子、坐标）一起调换。

Agent保留检索/看图工具，新增强类型的修改方案工具。项目、批次和身份由程序绑定，模型只提供精确工作区/原理号/行ID范围及预设操作；不支持SQL或任意代码。数据库事务根据当前事实生成逐行before/after并持久化proposal，业务行此时不变。仅浏览器明确确认调用Server提交接口，模型没有确认或写业务行工具。

支持字面端子前缀删除、整组端点调换、仅端子单元格调换和白名单字段赋值。默认整组调换交换端点元件/描述/端子和完整坐标对象，稳定行ID/批次/记录所属页/工作区/关联跨页索引保留。未知端点或坐标继续为空，不能编造位置。仅单元格调换、前缀和直接端子改值遵循既有坐标失效策略，预览明确展示清空坐标；整组调换携带另一端的有效坐标。历史提取证据保留，通过人工修订链接明确区别。

新增专用proposal表及两个service-role RPC。准备和提交都锁项目并检查所有者、处理/归档状态及当前批次；范围不静默截断，超过1000行要求缩小。提交比对完整匹配集合/行版本，任一变化整批拒绝；幂等确认不会二次调换。拒绝、过期和失权不能写结果。proposal保留操作者、时间、请求和逐行前后值；已提交proposal不可重放为新修改。

前端在正常流式回答之后展示修改对照和确认/拒绝；可分页查看全部变更，提交后刷新当前表格及后续解释的版本，不把旧引用当成新值依据。原只读解释兼容，不引入旧Supervisor/旧结果表。8000仍是浏览器唯一业务入口，复用8100宿主和现有独立Agent。

2026-10-18缺按钮修正：已确认新接口加载但模型会不调工具而口述已生成预览。真实proposal回执是确认界面的唯一依据；检测到无回执的生成声明时，清除本轮不实回复并受控补调一次，仍未执行则返回明确失败，禁止据口述文字制造可确认方案。新增公开answer_reset事件撤回未验证文本，正常解释仍流式输出；文本“确认”不代替提交接口。
