# ADR 0034：Explain定向重扫与辅助细节图

状态：代码、离线验收及本地Schema部署完成，2026-10-18；实际服务待用户重载，真实模型质量待用户复试。用户授权按原图/关联图加截图补充方式改造，提取核心不重写。Explain调用强类型rescan_connections工具创建持久任务，独立Worker复用已有Stage2扫描/补全/确定性校验；新的候选持久化适配器不发布业务行。共享8100和现有Worker，不增加端口或生产BackgroundTasks。

范围支持行ID、业务页、PDF物理页列表和工作区，身份/项目/批次/附件由程序绑定。工作区含索引中零记录页面，工具栏可在没有线表时准备重扫，用户可先附图再发送。附件经8000鉴权上传私有Storage，绑定会话、PDF物理页及source/target用途，校验实际图片；只传附件ID。原图始终读取并展示，辅助图只帮助辨字和匹配，不作为整页坐标系。现有Profile的裁剪与坐标回映复用，原图不能唯一定位时坐标为空且复核。辅助图通过重扫专用模型Gateway适配加入输入，普通提取请求完全不变。

Profile优先使用历史提取包与行证据冻结key/version/checksum，禁止回退到最新版本；原包不可用则明确配置失败。按项目/批次快照记录行版本和图纸索引，候选保存完整原图/附件摘要及Profile与调用信息。阶段事件、模型检查点持久化，租约过期可恢复，取消和失败不改线表。

终点定向重扫使用现有冻结来源事实的补全能力；整条/页/工作区重扫复用独立页Graph，仅更换持久化适配器。候选与已有行以所属页、原理号、端子和坐标保守匹配，不唯一则明确复核，不猜行ID。已有行更新保留ID/所属页/工作区/批次；未匹配的新连接作为新增候选，未再次识别的旧行不会自动删除。

Server只接受候选checksum和确认决定，提交时核对所有者、完整范围、批次、行版本和索引；事务更新白名单字段或新增已预览记录，保存前后值及新证据。候选产生/查看不修改正式线表。前端先公开回复后显示任务卡，异步刷新阶段与候选；用户逐行对照后确认。原解释、手动修订及首次上传提取链路保持兼容。

验收：92项Agent及提取兼容、27项API/项目管理、11项隔离SQL、27项浏览器通过；随后6项截图/布局与2项固定按钮复验通过，类型/lint/build、Ruff、18项Agent源码mypy及Server/部署脚本mypy通过。新增迁移20261018050000本地部署，原三张业务表摘要不变，REST元数据确认新RPC可见。未创建真实重扫任务、调用付费模型、提交实际业务修改或启停用户服务。见[Agent](../service/agent/changelog/2026-10-18-explain-rescan.md)、[Server](../service/server/changelog/2026-10-18-explain-rescan.md)、[Web](../apps/web/changelog/2026-10-18-explain-rescan.md)。
