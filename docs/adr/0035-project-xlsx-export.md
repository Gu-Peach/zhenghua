# ADR-0035 项目XLSX导出与按需重扫历史

状态：已实现并通过离线验证；需用户重载8000/8100并刷新前端。

新增鉴权GET `/api/v1/projects/{project_id}/export.xlsx`，返回XLSX二进制。权限由Server现有JWT与项目所有者路径校验；全量分页读取当前活跃批次正式线表，固定稳定排序，不接受客户端任意SQL/字段/Storage路径。处理态拒绝；完成前重新核对项目状态、版本及行ID/record_version清单，变化则409重试，避免分页期间混入已修改/删除的数据。无行时输出表头，无确认重扫候选不在业务表，不进入导出。

列顺序：页码、原理号、电压等级、端子排、起点代号、起点描述、起点端子、终点代号、终点描述、终点端子、电流、备注、色标。用户已确认电压等级与端子排独立保留。文本按文本单元格保存以保留前导零和防止原理号/端点中的等号成为公式；空值保持空，不补造电流/色标。冻结首行、筛选、列宽和换行支持人工核对。响应私有no-store，生成在线程中进行，不写业务数据库或Storage。

Explain的默认重扫事实范围收紧为当前会话与批次；显式rescan_id仍可按权限读取已有任务。前端不在普通打开时自动读取项目重扫列表，提供主动查看项目重扫记录入口；普通来源解释不应启动提取任务。拖动仅改变窗口位置，不产生Agent调用。

ExplainTurn新增向后兼容allow_rescan（默认true）；前端普通自动解释和已有任务差异解释显式false，工具列表隐藏重扫工具且执行边界二次拒绝。用户主动输入与重扫按钮请求沿用true，重试保存原轮权限，不能因重试扩大权限。

这轮只改变导出HTTP契约与聊天数据展示范围；无需迁移，保持候选确认边界。测试/启用说明完成后补记。

验收：79项Agent、37项API、54项浏览器，以及类型/lint/build/Ruff/mypy通过；其中导出11项覆盖13列映射、前导零/等号文本、0/空值、1002条全量分页、状态/权限/并发、二进制契约及CORS文件名。合成导出由独立Excel reader验证，artifact-tool导入作布局预览；没有改写导出文件。真实用户项目导出、模型质量与生产服务加载未在本轮执行。

运行时仅需要Python标准库编译该数据表所需OOXML，不新增Node或Excel进程/依赖；不把原理号/端点当公式。模块记录：[Web](../apps/web/changelog/2026-10-18-project-export-chat.md)、[Server](../service/server/changelog/2026-10-18-project-export.md)、[Agent](../service/agent/changelog/2026-10-18-explain-request-modes.md)。
