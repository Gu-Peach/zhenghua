# ADR-0038：图像驱动的规则配置对话

状态：已实现并通过离线验收。日期：2026-10-19。真实模型效果待用户核对。

用户希望拖入图纸或PDF后由Agent解释并生成规则，逐阶段确认，而不在界面切换三个阶段。沿用现有ProfileWizard候选/确认与版本校验，不改提取Graph或已发布Profile。

## 行为与契约

2026-10-19发布门槛按用户后续指示放宽：三阶段确认后，缺有效初扫起点为warning，不阻断导出/发布，端点原样留空；其他结构/确认/权限校验保持。见[设计](../service/agent/profile-permissive-publication.md)。

2026-10-19用户纠正提交时机：拖入/选择/粘贴附件只在输入区暂存，可以补充说明或移除；仅点击发送/按Enter后才建草稿、上传和启动读取。下文“首次上传/拖入自动读取”由这一约定取代；阶段确认后的自动继续保持。

- 首次发送附件可按文件名创建草稿，无需先输入名称；拖入/选择只暂存，发送后保存并请求读取，一轮最多4张图片。PDF每次最多50MiB，发送后才随机渲染两页，原PDF及其他页不保存；不足以说明接线/跨页时明确请求补充证据。
- 手动分类图片与PDF样图均逐图形成Expected（最多4图）；对话比较样图后生成可复用规则。
- 移除聊天界面阶段切换栏，当前阶段由持久化状态决定。候选先解释本阶段的输入→定位标记/标题栏→沿线/引用匹配→读取字段→不确定处理链路，再展示可修改规则与读图结果。
- 当前候选始终需要用户确认。确认完成后，界面以独立可重试轮次自动请求下一阶段；沿用实际已提供样图，缺少可读原图/对应目标页时追问，不编造。
- 上传PDF可用于当前任一阶段，新增PdfSampleInfo.stage（缺省classification）及PdfSampleRequest.stage三值枚举；重抽样仅使当前阶段及后续失效，保留前序确认和对话。PDF抽出的实际图片允许在后续阶段复用，取代ADR-0030的仅分类/后续必须手动图片限制。
- 用户可以通过聊天要求修改此前阶段。受控revision_stage选择classification/scan/completion，程序检查前序确认并撤销被修改阶段与后续确认；补全仍固定已确认来源端子，不能直接改写起点。
- 三阶段确认、校验通过后显示手动发布入口；自动继续不自动确认或发布。原表单兼容入口保留。

Server仍只代理可信身份，DTO经生成同步OpenAPI/TS，无业务库迁移。所有文件均在既有私有草稿沙箱内，原冻结包/项目不改。
