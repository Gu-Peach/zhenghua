# ADR-0043：人工复核与表内新增

状态：单行/范围审核均已实施并离线验收，本地迁移已安装，批量审核待8000加载API2.16.0；2026-10-20。

用户双击单元格编辑，待复核行才显示确认勾号。勾号单独确认该版本的人工复核，不通过空编辑隐式确认。新增 `POST /api/v1/connections/{id}/review`，输入 record_version、confirmed=true 和 Idempotency-Key；独立事务 RPC 校验所有者、项目可写、当前批次与版本，清除 needs_review，递增版本并记录 before/after、操作者、时间。允许人工确认留空字段，原始模型原因仍保留在 evidence/审计中；新提取/后续编辑仍可重新标记待复核。

目录从数据库当前批次全部待复核行聚合，不能依据当前搜索或100条分页判断完成。提取中/失败状态保持优先；已完成图纸的复核标记随当前待复核行变化，工作区由子图纸聚合，项目通过 needs_review_count 显示复核状态。原项目生命周期 status 不改写为新的枚举。

新增端子在同一表格插入本地草稿行，默认当前图纸（工作区/项目视图可在页码列选来源），填写后复用现有创建接口，取消零写入，失败保留草稿与幂等键。来源和批次冻结于草稿创建时，切换目录丢弃本地草稿；不再打开创建面板。

来源解释浮窗增加可访问的右下角缩放手柄，支持指针和方向键，限制在可视区域内，与标题拖动兼容。行操作和新增图标透明底，保持 Lucide 和焦点/悬停反馈。

迁移为新增独立函数，可回滚删除函数及撤回API路由，已有线表和复核审计保留。无生产Profile、Agent流程变化。

## 2026-10-20补充：一键审核

已完成行不再显示状态文案/标记，保留待复核/初扫/待补全和删除操作。最后操作列表头“一键审核”确认当前项目、工作区或图纸及搜索条件下全部待复核记录，包含后续分页；按钮tooltip明确范围，不只处理屏幕内100条。位置按用户最新要求由工具栏移入表头。

新增 `POST /api/v1/projects/{id}/connections/review`，输入当前batch_id、expected_updated_at、workspace_id/drawing_id/search与confirmed=true。Server验证目录归属并转换范围，独立事务RPC锁项目与所选行，核对所有者、可写状态、活动批次和项目版本，原子清除匹配行needs_review并保留逐行before/after审计与幂等回执。冲突整体拒绝，不产生部分确认；不改端子值/来源/范围外或已确认行。批量审核仍是用户显式确认动作，不经模型自动审核。

搜索沿用表格同样的字段和输入清洗。成功返回审核数量后刷新线表及目录；无待复核记录提示0，失败保留重试键。新增migration独立安装，不修改已应用历史迁移。
