# 登录后直接进入工作区

用户要求取消登录后的独立项目目录页。/projects有项目时replace跳转到固定排序的首个项目；无项目、加载中或列表失败时保留完整工作区框架，不创建占位项目。

新增EmptyWorkspace复用Header、空项目树和悬浮AI，中间提供上传入口、图纸/线表空态与规则引用入口。Header允许未选择项目，账号退出入口保留。原独立目录页的重命名/删除移到侧栏图标，删除当前项目后回到空工作区，重命名刷新当前项目标题。

13项浏览器回归、typecheck/lint/生产构建通过。新增首项目直达、空工作区窄屏/规则入口及侧栏重命名/删除用例；空态桌面及390px窄屏截图已视觉核对，文件位于.runtime/simple-management-browser。已有加载/失败/权限、上传、行编辑和跨页预览回归保持。

仅前端及文档修改，不改后端/数据库/提取规则，不调用模型。开发前端热更新后刷新即可；生产静态部署需使用新构建产物，本轮未部署站点。
