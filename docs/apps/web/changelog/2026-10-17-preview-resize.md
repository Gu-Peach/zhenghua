# 线表与图纸可调宽面板

2026-10-17。仅前端改动，复用现有图纸与坐标，不修改后端、数据库或用户运行中的服务。

图纸预览模式在线表和右侧图纸之间增加8px分隔条。可鼠标/触摸拖动，方向键每次调节2个百分点，Home/End调整到边界，双击恢复等宽。拖拽使用Pointer Capture，松开、取消或失去捕获后结束。同一项目内切换全量/预览保留本次比例，刷新页面恢复默认；容器变窄时自动限制两侧宽度，空间允许时每侧至少280px。760px及以下隐藏横向分隔条，继续上下布局。

缩放百分比使用独立56px按钮，图标/工具组不压缩，25%至400%均完整显示；点击百分比恢复100%。长标题省略并提供完整tooltip，窄屏工具栏按可用宽度排列，不产生空白高行或水平溢出。

实施位置：`ResizableResults.tsx`维护面板比例、尺寸观察和无障碍分隔条；`ProjectView.tsx`组合线表与预览；`DrawingPreview.tsx`及样式修复缩放工具栏。

验证：先用离线浏览器复现缺少分隔条；新增拖拽、最小宽度、键盘、双击、模式切换、窗口变窄及400%百分比溢出回归，并增加窄屏工具栏/分隔条检查。完整前端45项浏览器回归、TypeScript、ESLint和生产构建通过。登录页/工作台桌面和窄屏截图已检查，产物位于忽略目录`.runtime/preview-resize-final`。未运行真实模型或读写业务数据库。
