# 规则配置聊天界面

2026-10-17。Profile Agent默认进入聊天创建规则，原表单保留在`/agents/profile?editor=form`兼容入口。通过一次名称输入建立草稿，规则标识自动生成唯一值，名称/标识/版本在摘要中可见。

用户在同一个输入框发送说明、纠正或图片；支持PNG/JPEG/WebP上传与粘贴，每轮最多4张、每张10MiB。图片先保存到当前草稿，再随消息提供附件ID。Agent追问、处理状态与公开回复经SSE显示；Markdown安全渲染并逐字呈现，文字缓冲展示完才显示候选核对区。规则/读图候选位于聊天记录中，初扫可直接核对起点、终点、引用和放线标记，补全展示已确认起点到实际终点的摘要及证据路径。

用户可以在聊天中纠正，也可展开表格和规则说明编辑。修改表格后需明确保存或取消，禁止带未保存修改切换阶段/继续聊天；确认失败保留修改。草稿选择可恢复阶段及对话。停止接收、同消息ID重试、图片避免重复上传、错误/权限和手动发布保持清晰；已发布状态不伪造。旧草稿也可恢复，已有确认结果继续使用。

聊天与兼容表单、Markdown公共组件按需加载，主包约409KB，不将规则聊天依赖加载到初始工作台。业务请求及DTO处理集中在`apis/profile.ts`，类型来自生成契约。

验证：完整57项离线浏览器回归通过；最后按需加载变更另通过12项聊天/表单回归。覆盖追问、上传、文字纠正、三阶段确认/发布、刷新恢复、失败保留编辑、同消息重试、停止、权限与窄屏溢出。TypeScript、lint、production build通过，登录页及工作台/聊天桌面窄屏截图已核对；产物在忽略目录`.runtime/profile-chat-acceptance`和`.runtime/profile-chat-lazy-check`。没有调用真实模型或业务数据库。

使用前由用户重新加载8000业务API和8100 Agent，前端刷新。新API版本2.4.0，沿用已有服务启动命令。本轮没有新增数据库迁移，发布继续沿用原发布迁移和手动发布机制。
