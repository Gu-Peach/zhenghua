# 2026-10-17 三步规则创建向导

入口：用户菜单→智能体中心→规则配置智能体。新建规则标识/名称，按拆分分类、本页提取、跨页补全三个步骤上传图片和描述；AI生成规则摘要与Expected候选，用户编辑并确认。

分类显示元数据表单；扫描/补全显示连接表，可修正端点、补行、增删跨页引用、查看完整字段。图片可放大，补全来源固定为初扫原图，目标图填写工作区与页号；支持额外不应提取的负例。任务身份固定，跨页初扫终点不能提前补造。

草稿列表、已上传图片、候选及确认状态从Server恢复。处理中禁用重复操作；失败保留编辑，版本冲突提示刷新；未保存修改禁止发布，更新输入要求重新生成。确认后规则、图片案例、Expected及manifest一起保存，前序更新使后续失效。

只有用户点击“发布规则”才提交发布，成功前不伪造已发布状态；失败可重试。新规则随后进入提取Skills/上传选项，既有项目不重绑。本轮不接规则诊断聊天或现有规则编辑向导。

验收采用离线HTTP夹具，包含三步流、修正后确认、刷新恢复、加载/失败/权限/长文本状态、发布失败重试及登录/工作台桌面与窄屏截图。真实模型与正式发布由部署后人工验收。
