# 项目名原地编辑与目录升序

2026-10-17，范围仅apps/web及前端文档。用户澄清本轮只支持项目改名，工作区目录暂不改名，不创建浏览器别名或后端接口。

项目树名称和中间当前项目标题可双击原地编辑；Enter/失焦保存、Esc取消，空值校验，保存中禁用，失败保留草稿及就地提示。沿用既有项目PATCH接口，无window.prompt或重命名铅笔。F2编辑与正常链接导航保留；鼠标单击项目名延迟240ms确认，避免双击非当前项目时第一次点击就导航并卸载编辑器。键盘/修饰键链接沿用原生导航。

projectApi.get在前端映射后，按工作区code及图纸业务页号自然升序：006.C → 006.M → 082.R，006M01 → 006M2 → 006M10。页号相同时按PDF物理页/ID确定顺序。项目列表仍使用服务端固定创建顺序；目录排序在增量刷新后保持一致。侧栏和图纸库共用同一数据，图纸主标签仅显示编号，保留PDF物理页元数据。

不改变工作区编号、图纸ID、PDF物理页、API契约或后端提取顺序。本轮没有后端实现修改、真实数据库/模型调用或服务启停；用户保存项目名称仍通过现有服务端权限检查持久化。

验证：新增6项管理浏览器场景，21项管理与11项Explain合计32项通过；typecheck、ESLint、production build及git diff检查通过。覆盖原地保存/失败/空值/Esc/失焦去重、非当前项目编辑/导航、排序/物理页保持、图纸库、增量更新、长文本及窄屏。登录/工作台桌面与窄屏、目录升序/编辑失败/保存中截图已检查，位于被忽略的.runtime/simple-management-browser。
