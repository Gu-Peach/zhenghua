# 2026-10-18 Explain细节图与异步重扫候选

来源解释框新增添加/拖拽/粘贴图片，先选择原页/关联页用途与所属物理页，最多6张、单张8MB。缩略图可移除此轮选择；上传失败可见，上传中禁止发送。附件ID由会话绑定，重试同一turn保留原附件列表，避免静默换图。

左侧选中工作区或图纸后，工具栏“重新扫描”可在没有线表时打开准备窗口、预填中文范围；不会立即调用模型，用户可先上传细节再发送。未选择范围时按钮禁用，不默认全项目。未分类业务页可按可信物理页列表重扫。表格搜索不扩大或改变左侧所选范围。

普通解释和手动修改继续使用原入口。模型创建重扫任务后先显示公开回复，逐字缓冲完成后显示任务卡。卡片按2秒补读API快照，支持取消、断线错误/刷新、恢复已持久任务；关闭解释窗口只停止前端读取，不取消Worker。阶段结果只显示进度，不替换正式线表。

候选显示更新/新增、原所属页、字段before/after、未唯一匹配与复核提示，每25行分页。可展开实际原图及上传细节的签名缩略图，或让助手解释已有任务差异。确认/拒绝只提交checksum和决定；成功后刷新表格并使用Server真实版本追问，保留当前所属页/工作区筛选。冲突/无权限不伪造成功，旧值保留。

使用Mock接口验证截图上传/关联页绑定、粘贴失败、先回复后任务、异步候选、确认前旧值、确认刷新、取消、冲突及窄屏长文本；旧Explain/编辑/登录回归保持。截图与运行结果保存在忽略的`.runtime/simple-management-browser`，未访问真实模型或业务数据。端到端真实图纸质量仍需用户启用服务后验证。

最终27项浏览器及后续6项截图/布局、2项固定操作栏复验通过，类型/lint/build通过；桌面/窄屏、登录页与长文本/失败状态已核对。确认/解释按钮在候选操作栏保持可见，ready后不再显示“正在处理”；上传控件独立设置宽度，避免被原发送按钮样式挤压。无图的普通解释不发送新增附件字段，保持旧入口兼容；新功能需同步加载API2.8.0和8100。
