# 提取未完成提示支持关闭

线表工作区顶部的提取失败/部分未完成提示新增右侧Lucide关闭图标，支持点击、键盘及可访问名称“关闭提取提示”。关闭仅隐藏当前挂载页面中的提示，不改任务/结果/失败状态；刷新页面可以重新查看。任务转为处理中时组件卸载，新失败或新错误内容会重新展示。原“重试提取”行为保留。

实现位于 `ExtractionFailureNotice.tsx`，由 `ProjectView.tsx` 按任务/错误内容挂载，样式沿用错误提示背景并保持右侧关闭按钮在窄屏可见。不新增API或数据库变更。

验证：TypeScript类型检查、ESLint、生产构建及diff检查通过。初次lint/build受沙箱依赖读取限制，使用允许读取本地依赖的命令后通过。隔离HTTP夹具浏览器核对桌面/390px窄屏、空表/加载、失败/无权限、长文案、键盘关闭及保留重试；8份截图保存在忽略的 `.runtime/extraction-notice-check/`，包含登录页桌面/窄屏。没有访问实际数据库、调用模型、重试真实任务或重启用户服务。
