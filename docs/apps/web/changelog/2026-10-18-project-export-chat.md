# 系统名称、项目导出与聊天窗口

系统Header、首页可访问名称、登录页和页面标题统一为“振华重工放线表提取系统”。当前项目根范围显示“导出XLSX”；选择工作区/图纸后隐藏，单击左侧当前项目名称回到全项目范围并清除页/工作区/搜索筛选。下载仍始终导出全项目当前批次正式结果，不受显示分页和搜索限制。导出等待/失败/冲突可见，文件名取服务器UTF-8响应头，私有鉴权下载后回收临时URL。

用户确认的13列：页码、原理号、电压等级、端子排、起点代号、起点描述、起点端子、终点代号、终点描述、终点端子、电流、备注、色标。用户只提供字段需求，黄色表头/边框/冻结首行/筛选由Server统一生成；原始空值不填造内容。

Explain标题栏可用鼠标/触摸拖动，释放或取消后结束捕获；限制在视口内，窗口尺寸变化重新约束。标题栏可聚焦，用方向键移动、Home恢复默认位置。按钮/输入不参与拖动，草稿、回答、会话保持，拖动不会调用Agent。

此前普通打开时会自动读取该项目全部最近重扫任务，导致082R50解释下出现006.M历史已提交卡片。现在只展示当前会话任务；用户点击标题栏“查看项目重扫记录”才读取历史列表，不启动重扫。普通自动解释和既有重扫差异解释显式allow_rescan=false，前端重试保持原值；自然语言主动输入和重扫按钮保留原功能。
