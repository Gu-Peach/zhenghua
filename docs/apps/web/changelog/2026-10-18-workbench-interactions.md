# 工作台图纸导航与Explain消息布局

图纸预览使用统一`useDrawingNavigation`：滚轮按鼠标指针位置缩放，范围25%—400%；按住中键拖动滚动位置，松开/取消/丢失捕获时结束。图片与归一化标注处于同一容器，保留缩放按钮、100%恢复和滚动条。缺图/加载失败时不拦截图纸区滚轮，原有刷新入口保留。

项目标题旁提供目录收起/展开按钮，桌面和窄屏均可使用。目录隐藏时释放布局空间，恢复后保留工作区/图纸选择、展开状态及原调整宽度；空工作区也保留入口。按钮带可访问名称、aria-expanded和aria-controls。

点击工具栏“重新扫描”即打开Explain并自动发送当前图纸/工作区的完整重扫请求，不再预填输入框等待用户点发送。范围来自左侧选择，沿用现有Explain流式接口与工具调度；生成候选后的确认保存流程保留，未增加自动提交权限。关闭浮窗仍按原逻辑停止当前解释，已入队任务由显式取消控制。

关联图纸放入所属消息中、排在回复正文之前，正文流式增长及下一轮问答正常向下排列，历史证据留在历史轮次。确认修改后的旧图纸仍作为原轮次证据，不再充当最新回复的固定图纸栏。点击普通来源图片或重扫证据，打开浏览器中央的原生dialog，复用滚轮/中键导航、提供缩放/关闭按钮；Esc仅关闭放大窗并返回缩略图焦点，不关闭Explain。加载失败显示安全提示，签名URL权限路径保持原有机制。

验证：先运行30项Explain/修改/重扫浏览器用例，再运行54项图纸/管理/Explain/重扫用例，去重共65项；均为本地HTTP/SSE夹具，未接真实数据库或付费模型。新增3项交互测试、更新空范围重扫测试；覆盖缩放指针位置、中键位移、目录选择恢复、按轮DOM顺序、dialog居中/焦点/Esc、窄屏无溢出及点击后自动发送。TypeScript、ESLint、production build通过。检查桌面/窄屏登录及工作台、放大窗/追问和真实比例SVG标注截图，产物位于忽略的`.runtime/simple-management-browser`。

无需新依赖、后端契约、数据库迁移或新启动命令；已有Vite服务刷新生效。未重启用户服务、发起真实重扫或提交实际业务行。实现计划见[计划](../workbench-interaction-plan.md)。
