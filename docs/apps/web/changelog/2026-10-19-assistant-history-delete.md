# 主助手历史列表行内删除

- 将原生select改为自定义历史面板，每行右侧提供Lucide×及可访问名称/完整标题。可直接删除未恢复的历史会话，无二次确认；当前行显示选中标记。
- 调用真实DELETE接口，成功后移除列表行。删除其他对话保留当前会话、文字和附件；删当前对话清空消息、草稿和对应本地恢复ID，回到新对话。失败保留内容和列表，可再次点×。
- 回复、恢复和删除期间禁用冲突操作；同步锁防止重复删除，异步选择代次保护避免旧响应恢复已删历史。
- 支持ArrowDown进入、Tab访问、Escape返回触发按钮、点击外侧关闭；窄屏长标题省略并提供title，×始终可见。

12项主助手浏览器测试、typecheck/lint/build通过。新增覆盖直接删其他历史不恢复、草稿附件保持、刷新移除、删当前/清本地记录、失败重试及窄屏键盘操作。桌面/窄屏截图已核对，归档 `.runtime/assistant-conversation-deletion/`。

依赖API2.13.0及新数据库迁移；本地已安装且运行API已加载，刷新Web即可。详见[Server交付](../../../service/server/changelog/2026-10-19-assistant-conversation-deletion.md)。未删除实际用户会话或调用模型。
