# 规则配置改为聊天引导

主聊天页面移除三个阶段切换按钮。按用户后续纠正，图片/PDF拖入聊天记录区或输入区后仅暂存，点击发送或Enter才保存证据、启动读取，尚无草稿时按文件名建立。图片一轮最多4张、单张10MiB；PDF一次一份50MiB以内，只抽两页。混合文件、超量、不支持格式和繁忙状态均明确提示。最新验证见[显式发送修正](./2026-10-19-profile-explicit-send.md)。

每次展示当前阶段的识别链路、依据、规则和可修改识别结果。用户可聊天提出意见或展开表格修正，确认后自动以独立轮次尝试下一阶段。重试仅重试当前轮；缺少目标图时继续聊天补充，不自动确认或发布。此前保存会话的下拉删除保留，旧表单兼容入口保留。

图片选择、粘贴、拖拽与PDF选择、拖拽均先添加待发送附件，可以补充说明或移除，发送后才读取；当前阶段任意时可补充。最终三阶段确认且校验通过后，由用户点击发布。

验证：22项会话浏览器、最终7项定向复验通过（去重24项，其中2项登录/工作台截图），含拖拽自动建草稿、多图、PDF阶段补充、纠正、确认边界、禁止提前发布、取消/失败重试、键盘、窄屏/长文本及原会话删除回归。类型检查、lint和生产构建通过。截图在忽略目录 `.runtime/profile-guided-browser`、`.runtime/profile-guided-final`，不提交产物。

未操作真实会话/模型或用户服务。需重载8000、8100并刷新前端，加载新PDF契约；无新增数据库迁移。PDF未抽到实际接线页/对应目标页时会请求补图，不宣称已读取其余页面。设计见[ADR-0038](../../../adr/0038-guided-profile-authoring.md)。
