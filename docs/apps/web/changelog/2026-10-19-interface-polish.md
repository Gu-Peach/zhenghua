# 浅色专业工具界面统一

按用户的截图与优化方案，在当前 Web 上增量调整；保留已有未提交功能。

## 行为与视觉

- 新增 `src/assets/interface.css`，统一浅灰页面、白面板、`#0B8085` 主色、14px 正文、12px 辅助信息、36px 操作按钮、32px 图标按钮和可访问焦点。工作台 Header 改浅色。
- `ChatIdentity` 用于主助手、来源解释、规则创建和规则辅助编辑：用户在右侧浅青气泡，助手在左侧显示头像/名称，工具为灰色折叠记录。来源解释正文排在对应图纸缩略图之前。
- `ConnectionChangeList` 将修改与重扫字段按连接记录折叠，保留全部原值/新值、坐标字段、25条分页及完整删除清单。卡片显示范围、待确认/已保存状态、删除/写入数量；确认行为仍调用原有受控接口。
- 主助手可切换右侧420px停靠/浮窗，桌面停靠重新分配工作台宽度。1100px及以下自动使用浮窗；关闭或进入独立解释时释放停靠空间，会话保持。
- 聊天标题和输入区固定，中间内容滚动。来源解释将图纸/附件设置折叠，缺所属页时自动打开；规则编辑将建议放入同一消息滚动区，减少多层滚动。
- 规则创建初始提供图纸上传引导；智能体卡片统一状态标签与底部操作位置。Skills名称优先、版本和北京时间次级显示，长标识默认折叠，仍可搜索。删除使用轻量图标。
- 线表字体与表头可读性提升，电流用中性文字；复核使用已有状态标签和行首局部标记。

## 使用与边界

已有Vite开发服务刷新Web即可；静态部署需重新构建并按原发布流程部署。此轮无环境变量、API、数据库或Profile变更，无后端重载要求。

主助手停靠偏好仅存当前组件内存，窄屏不提供停靠按钮。原有接口未开放时仍显示未就绪/失败，不模拟可用能力。

未调用真实VLM、写实际业务数据、发布规则或启停用户现有服务。构建仍有超过500kB的分包提示，本轮不扩大到打包重构。实现计划见[界面统一计划](../interface-polish-plan.md)。
