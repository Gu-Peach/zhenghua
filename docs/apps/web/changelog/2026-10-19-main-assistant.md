# 全局主助手接入

右下角主助手由AppLayout维护，切换项目、工作区或智能体页面不销毁会话。支持历史会话恢复、新会话、工具执行记录、公开答复、真实任务与规则/线表差异确认卡。

- 检索导航使用固定路由映射，`workspace`保存真实工作区ID，`drawing`保存图纸ID；跳转后校验项目索引、选中目录并读取结果。URL可刷新或后退恢复。
- 唯一目标直接跳转；多个目标提供真实候选供用户选择。等待期间用户已切页时，迟到导航保留“打开目标”按钮，不强行切回。
- 图片/PDF选择、拖入或粘贴仅进入输入区，发送或Enter之后上传；Shift+Enter换行。参考图可标注用途及PDF物理页。
- 重扫卡复用现有完整差异、分页、原图及候选确认，普通线表修改也复用既有预览组件；确认通过主助手action摘要提交，刷新正式表格。
- 规则建议提供真实文件before/after，确认按钮一次应用并发布指定方案；文本“确认”不会替代按钮。失败保留输入和同轮重试，恢复任务不重新创建重扫。
- 可定位数据库规则，在原规则资源界面查看和编辑；独立Explain打开时主助手隐藏以避免浮窗重叠。原Explain/Profile入口保留。

本次前端全量123项模拟浏览器测试通过，包括8项主助手专门场景及原登录/项目树/来源解释/重扫/规则编辑回归。TypeScript、lint、production build通过；构建保留大chunk建议，不阻止构建。桌面/窄屏和空、加载、失败、权限、长文本截图位于 `.runtime/main-assistant-all-final/`，不提交。
