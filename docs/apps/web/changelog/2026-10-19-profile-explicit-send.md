# 附件先暂存，由用户发送

修正图纸拖入后立即发送的问题。图片拖拽、文件选择和粘贴仅在输入区显示待发送预览，PDF选择/拖拽仅显示待发送文件名；用户可补充说明或移除。点击发送或Enter后才建立草稿、上传附件、抽PDF样图和请求Agent。Shift+Enter保留换行，附件没有文字也能发送。

PDF有独立暂存状态和移除按钮，混合PDF/图片继续拒绝。草稿恢复/新建时清理暂存，删除其他会话保留当前编辑。附件待发送时不能确认旧候选或发布，避免把未读取附件与旧结果一起确认。发送失败保留原重试流程和请求标识。阶段确认后的自动继续保持。

验证：23项会话浏览器检查全部通过（首轮22项通过，原生ClipboardEvent测试修正后剩余1项复验通过），另2项登录/工作台桌面和窄屏通过，去重25项；类型检查、lint、生产构建通过。新用例断言未发送时无草稿读取、附件上传、PDF抽样或对话请求，覆盖图片Enter、PDF发送按钮/Enter、说明保留/移除、粘贴、Shift+Enter、PDF重试及原阶段流程。
