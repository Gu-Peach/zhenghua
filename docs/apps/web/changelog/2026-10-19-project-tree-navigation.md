# 项目目录默认收起与导航跟随

用户反馈大型项目目录初次全部展开，点击靠后图纸后又回到项目根部。工作台以完整查询参数为key重建，原目录的局部展开数组与滚动位置随之丢失。

本次将目录UI状态放入无持久化的project-tree-store，保留现有工作台重建、筛选初始化、预览及Explain生命周期。项目/工作区分支以项目ID隔离命名，初次默认收起；用户点击工作区名称会打开当前分支。当前导航所指祖先自动展开，其他未操作分支保持收起；用户仍可手动关闭当前分支，同一选择下不会被强制重开。

树容器按项目记录scrollTop。只有图纸索引加载完成后才恢复，避免加载时DOM高度不足把原位置覆盖为0；恢复后将选中节点按最近边缘滚到树内可见，既不固定到项目根部，也不滚动整个页面。前进/后退、深层链接和主助手导航复用选中状态；用aria-current/aria-expanded暴露当前页及展开情况。位置更新不会导致整棵树随每个滚动事件重渲染。

刷新浏览器或切换/退出账号后内存状态清空。普通根路径再次进入默认收起；带工作区/图纸的深层链接只展开目标祖先。数据、API和目录自然排序保持，未操作实际数据库或运行服务。

验收：81项相关测试通过（含3项新增长目录/默认收起/历史跳转/窄屏容器滚动，以及线表、答案对比、Explain和主助手回归）。原测试按新默认行为显式展开需要的目录，不绕过交互。类型检查、lint、production build通过；桌面/窄屏目录跟随和登录/工作台截图查看完成。合成HTTP夹具最多700张图纸，无模型调用/真实业务写入；截图位于忽略目录.runtime/project-tree-regression/。刷新Web即可使用，无迁移或服务重启要求。
