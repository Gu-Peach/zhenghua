# 范围替换预览与新结果追问

全量重扫候选显示确认后删除/写入数、全部待删旧行（25行分组查看完整字段）及新结果。空结果突出提示“确认后所选范围将被清空”，仍需用户按钮确认。旧版全量或不完整替换候选禁用确认，可拒绝或重新扫描；局部仅显示选中行/字段修订。必须成功取得持久化完整候选，才启用确认，避免SSE省略空值导致预览不完整。

全量删除产生新行ID，当前行被替换时，解释入口切到所属页并建立新会话，保留历史问答显示但不继续查询旧ID；不自动触发新解释或重扫。清空旧附件选择并用新会话绑定后续上传，移除已失效编辑方案；表格清空当前行选择/搜索并回到首组，工作区/图纸筛选保持。局部修订仍使用原行ID/新版本。

35项相关浏览器用例通过：删除/新行完整预览、确认前保持原值、空结果删空、旧候选禁用、持久候选加载保护、新会话追问与原局部/手动修改/权限/拒绝/取消/桌面窄屏回归；TypeScript、ESLint、production build通过。已查看桌面替换、窄屏删空及登录截图，产物在忽略的.runtime。

需本地新迁移（已装）、8000 API2.10.0、8100和实际Worker加载新代码，再刷新Web并新建任务；API缺迁移拒绝确认，旧任务不转成删除式替换。未操作真实线表或调用模型。见[ADR-0036](../../../adr/0036-rescan-scope-replacement.md)。
