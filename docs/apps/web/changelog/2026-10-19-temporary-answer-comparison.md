# 临时标准答案按页对比

工作台新增“答案对比”入口，支持在选定项目中本地导入XLSX。用户确认1641.xlsx用于1002001641 PERU TPP 1 STS，文件不随代码发布，不自动关联其他卷盘项目。使用说明和边界见[设计](../temporary-answer-comparison.md)。

- 答案只放无persist的Zustand内存store，按项目ID隔离。切换目录/路由保留；清除、删除项目、刷新或退出登录清空，不上传或写数据库/Storage/浏览器持久存储。
- 答案按业务页建立索引。每次只读取所选图纸的完整提取结果，固定批次，排除主表搜索/当前100行分页，单页最多50000条；批次变化、短分页或重复ID拒绝判定。请求切换后旧结果不覆盖新页。
- 仅对比答案实际提供的列，保留空值、0、端子符号和方向；完整一致优先消耗，再按唯一端点/唯一原理号匹配。多条同号仍不确定时标为待匹配，不按顺序配对；逐字段高亮，单列漏提、多提。
- 每50组渲染，支持仅看差异、页选择、刷新和清除。答案未提供当前页时不判多提；答案页未关联图纸或结果读取失败时只展示答案、不判漏提。提取进行中明确当前结果为暂态。
- XLSX解析器read-excel-file9.3.12按需加载，无远端文件解析接口。支持10MB/50000条以内，损坏/加密/缺表头/多工作表字段不一致明确报错，替换失败保留旧答案。

验证：12项新增测试（4项纯函数+8项真实文件/HTTP夹具浏览器）以及23项原工作台回归分批通过；类型检查、lint、production build通过，保留已有大chunk建议。桌面/窄屏对比及登录/工作台长文本截图已查看。真实XLSX只读、业务接口使用夹具，不操作实际项目结果/模型或运行服务；缺本地答案资产的环境明确跳过对应8项，合成纯函数仍可运行。

启用：现有安装环境已更新依赖；其他开发环境执行corepack pnpm install。刷新Web，进入对应项目→答案对比→导入答案XLSX，选择本地1641.xlsx。无需新迁移、API/Worker重启或规则发布；刷新后需要重新导入。
