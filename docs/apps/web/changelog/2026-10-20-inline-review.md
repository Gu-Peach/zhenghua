# 线表确认、表内新增和聊天缩放

按用户需求移除线表行的铅笔；仅待复核行显示确认勾号，已完成行不显示。双击单元格编辑、Enter保存、Esc取消保持；编辑/确认期间禁用新增，避免重叠草稿。勾号通过独立版本化API保存人工确认，成功后刷新行、图纸、工作区与项目状态。失败显示消息，重试复用幂等键。

行操作和新增图标采用透明底Lucide，保留可访问名称、焦点及悬停反馈。新增按钮在当前表格插入本地草稿，默认当前图纸，页码列可选来源及跨页目标；不再弹出面板。批次冻结于开始填写时，保存失败保留输入/幂等键，取消不写入；切换目录/搜索/分页丢弃草稿。错误提示固定在工作区上方，横向滚到右侧仍可见。

来源解释聊天浮窗右下角增加缩放手柄，支持拖动/方向键与Home恢复，限制在当前视口，与标题拖动及窄屏兼容；缩放不会发起模型调用。
