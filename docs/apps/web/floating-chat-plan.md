# 图纸库层级展开与悬浮聊天

日期：2026-10-13。按用户新要求替代图纸库平铺和固定右栏展示；不变更 API/数据库契约。

## 行为

- 图纸库根节点为当前项目名称，展开工作区文件夹，再展开具体 PNG 页；点击只展开/收起，不切换路由、线表区或线表过滤条件。
- 图片展开后才通过既有 projectApi 查询签名链接，复用 DrawingPreview 的缩放/失败刷新；加载、空目录、失败/无权限状态在原目录显示。
- 工作台保留左侧导航和中间内容两列，聊天以固定悬浮窗口呈现，右下角按钮负责开关，窗口有关闭按钮和 Escape 关闭。
- 普通项目默认收起，刚上传 PDF 时打开确认提示。隐藏窗口保留组件和草稿；异步订阅及消息状态由项目页面继续维护，收到进度时按钮显示提示。
- 窄屏窗口尺寸不超出视口；对话窗口为非模态，可继续操作业务内容。
