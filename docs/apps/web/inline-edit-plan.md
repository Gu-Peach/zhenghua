## 编辑契约

- 双击可编辑字段或点击行编辑按钮，在原表格行显示输入；Enter 或行内保存提交当前行的已修改字段，Esc 或行内取消放弃草稿。
- 页码、线号保持只读。电压等级、端子排的同线号共享语义沿用 Server；修改映射统一放在 apis，不在组件拼接 DTO。
- 开始编辑时冻结行及保存回调的结果版本/revision；后台更新不自动替换编辑基线。失败保留输入与相同内容的 Idempotency-Key，用户可取消并刷新。
- 只有成功响应后退出编辑，刷新库中分页结果；不在提交前冒充保存成功。
- 新增端子仍使用现有新增表单；本次只替换记录编辑弹窗，不改变 API/数据库。
