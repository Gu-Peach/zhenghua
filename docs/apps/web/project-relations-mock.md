# GCR101 跨项目关联演示

本轮是前端交互演示，关联事实不进入正式线表、API、数据库或 Storage。保留现有项目、编辑和提取功能。

## 展示与数据边界

- 项目顶部在“答案对比”旁增加“关联项目”。选中 1002001693 大车卷盘项目的 GCR101（原图 1A，PDF 第2页）时显示关联图谱。
- 前端 `apis/mock/project-relations.ts` 保存两个模拟项目及端子映射，固定 Mock 标识；只有可见的大车卷盘项目存在时才挂入项目目录的 Mock 文件夹。
- 低压配电系统承接 0261（XD10:13/14/15 与 X1:1/2/3）和 0262（XD21:7/20 与 X21:1/2）；照明配电系统承接 0263（XD22:90、N-BAR 与 X22:1/2）。各组另含 PE。
- 上述外部项目、页码与图谱均属模拟，不能视为已核验跨项目连接。真实项目内现有提取记录保持原值。
- 图谱显示当前页、关联项目及电缆分组，明细列出实际端子对。项目节点和明细链接可跳转到模拟项目对应页，支持返回原项目 GCR101、刷新与浏览器前进后退。
- 模拟项目采用只读工作台，不触发后端项目详情/线表/导出/重扫/编辑/删除，也不提供不存在的 PDF。
- 非 GCR101 显示无演示关联；正在加载和无访问权限时不展示关系。

## 实现与验收

1. 前端设计（本文件），实现前登记 TODO。
2. 独立本地数据/关系组件/模拟项目工作台，增量接入现有 ProjectView/ProjectTree。
3. 类型检查、lint、production build；HTTP 夹具验证目录、页级过滤、10条端子映射、两项目往返、刷新、空态/失败/权限/长标题与窄屏；确认没有 Mock 业务请求或写入。

本轮不改变正式公共契约。后续真实跨项目关联需要独立设计所有者权限、稳定项目/图纸/端点身份和确认流程，本轮不预设数据库实现。
