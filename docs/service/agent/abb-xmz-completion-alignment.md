## 设计

- 公共机制为“初扫当前页 → 冻结来源事实 → 只读目标局部图 → 坐标还原”，继续使用同一页工作流，无新增模型定位调用。
- 将原ZH目录下的纯图像裁剪与精简任务投影明确提取为共享基础设施，旧导入保留兼容入口；ZH配置与端子语义不变。ABB/XMZ通过各自Adapter补充原生页标，公共Graph不增加vendor分支。
- ABB使用Sheet和1～6列图框，XMZ使用SH.NO.和01～48列图框；裁全高竖带保留上下边界回指，以各Profile的列宽配置决定范围。列缺失/冲突/越界或不支持布局时沿用整页回退，不猜位置。
- 精简任务保留来源/目标业务页、原始引用、信号/电位、原理号及已有电流；不传来源图片、来源针脚或坐标，终点从目标图独立读取。XMZ的GCR可逆索引同时提供原生SH.NO.，避免用编码页号视觉匹配。
- 初扫添加signal_name匹配提示；原理号仍按各模板规则读取/拼接。ABB小圆圈与Sheet原理号、XMZ放线斜杠与原生X排号保持独立。
- 一组Stage2来源图；Stage3仅对应来源连接，运行时最多选一个案例。历史键stage3_cases继续表示页工作流内部补全，不恢复独立Stage3。
- 局部图替代整页，维持旧整页的实际输入像素上限；Few-shot同样临时裁剪、坐标换算，已知点不在范围内则案例回退整页。最终JSON/XLSX仍为整页坐标，数据库/API字段不变。
- 空响应必须给出明确end决定与依据，仍仅使用已有最多两次Schema尝试；错误或未找到保留原因并继续后续任务。此协议独立于ZH端点语义。

验收仅做静态资源/Schema/摘要/类型核对和离线图片预览，不执行pytest、Fake VLM、真实模型、业务数据库或运行服务操作。真实精度由用户新目录复测。
