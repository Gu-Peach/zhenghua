# 本地ZH测试脚本的Profile错误隔离

## 原因与修复范围

用户将大车卷盘Prompt目录移动/精简为xmz后，其Profile仍引用prompts/zh_gantry_reel。脚本只使用ZH，却在启动时严格加载全部Profile，导致ZH资源有效时也抛出ProfileRegistryError。错误处理只显示异常类，未显示缺失资源路径。

修复仅限本地run_stage2_groups.py：允许Registry收集其他模板的错误，绑定ZH时仍执行既有完整性校验；ZH自身无效必须停止并保留具体原因，不启动模型。其他无效模板告警后跳过，不修复或恢复用户正在整理的资源。不改变服务主入口的严格加载策略。

## 验证状态

脚本隔离加载、Profile错误报告及回归文件修改完成。修改前确认唯一Registry错误来自大车卷盘旧资源路径；修改后直接调用资源绑定函数，确认ZH2.0.2与当前初扫Prompt有效，错误报告包含具体原因。git diff --check通过。

新增参数化回归覆盖无关模板失效不阻塞ZH，以及ZH本身缺失资源仍拒绝绑定、错误报告保留路径。按用户自行测试要求，未运行pytest、冒烟、真实模型或提取脚本。未写库/Storage、生成提取结果或恢复用户删除的资源；端到端重跑待用户执行原命令。
