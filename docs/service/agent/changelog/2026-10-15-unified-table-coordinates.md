# 三种模板统一14列与端子坐标

按用户要求，主表全部对齐ZH当前字段和语义，决策见[ADR-0019](../../../adr/0019-unified-extraction-table.md)。

## 实现

- 新增domain/table_output.py，唯一维护14列表头、主表行映射和ZH默认字体/灰表头/列宽；公共Graph、状态初始化、分组JSON/XLSX、原生记录XLSX主表与本地拆页脚本引用该契约，色标为空。
- 元件优先device再用location，描述只用name；端子直接保留规范化后的实际值，不再在某个入口额外拼设备前缀。业务备注只取remark，source_note/part/原始位置保留在记录JSON和原始提取诊断页，不挤占描述/备注。
- 原生主表匹配ZH默认样式，坐标两列42宽，自动估算行高；已有自定义模板仍按其显式样式读取。固定业务导入模板维持自身布局。
- 通用Schema与调用说明明确terminal_coordinates，模型须提供实际端子符号/接点中心的整图归一化x/y和本端PDF物理页，无法确认时null；跨页不改来源坐标。Pydantic仍接受旧记录缺省坐标，现有物理页绑定/坐标校验和来源冻结保留。
- ABB1.1.4/XMZ0.1.2同步初扫/补全Prompt、适配器、图像expected和manifest checksum。ABB示例29个已知端点、XMZ34个已知端点给出人工目视坐标，未标针脚为空；只是教学位置近似标注，仍待工程复核，不宣称像素级准确率。ZH现有全部示例坐标保留。
- XMZ不再继承ZH柜号专属device说明，三者仅共用输出结构/坐标协议，保留各自符号、页标、端子和原理号规则。

## 边界与检查

不重跑模型、pytest或数据库，不发布、不覆盖旧结果、不生成新的测试XLSX。已补离线回归文件，覆盖三种模板相同主表、原生XLSX主表、坐标/物理页保留和未知留空；本轮只做语法、资源路径、Pydantic Schema、checksum和只读绑定静态检查。主表视觉布局和真实坐标识别需用户新目录复测；旧结果没有的坐标不会自动补出。
