# ZH 跨页引用与终点读取修正

本地ZH2.1.1，manifest v12，补全上下文v2。依据用户003.C/004.C复测及原图核对，设计见[方案](../zh-cross-page-reading-fix-plan.md)。本轮没有运行测试/模型、写数据库或覆盖旧结果；工作区其他前后端/Server改动保留。

## 变更

- 初扫维持放线标记优先，补充地址按工作区/对象/斜杠后业务页列拆开读取，禁止拼接对象尾部数字；强化仅接收段不反向创建、一个放线段不穿越端子重复输出。初扫图片数量保持5组。
- ZH补全上下文v2移除来源完整端子、坐标及可能包含来源端子文字的方向描述，state原始事实保留。只传来源/目标业务身份、来源元件元数据、原理号、信号名、绑定引用和电流。旧v1紧凑任务会投影为v2；真实输入与Few-shot一致。
- 补全步骤改为匹配对端回指线路→沿线向页内找最近实际接点→分别读接口/针脚→组合完整端子→读取目标接点坐标。080C50回指在页底且朝外，取消必须找到入页箭头的限制；终点归属来自任务，不重新交换方向。N-BAR/PE-BAR按独立母排读取。
- 模型地址不可定位时，仅在相同来源物理页、工作区和对象下有唯一PDF原文地址且目标可用时核对恢复。同址重复可合并，多地址（包括不可用候选）仍不猜；有列号时还需对应列号。`raw`保留模型识别文本，新增可选`references.source_index_raw`记录程序核对的原文，忽略模型自报的该字段。可用的原始地址不被替换。
- ZH语义完整性校验拒绝只有接口而没有针脚的X2/X2:X2等值并清空其坐标、保留记录待复核；不新增端子家族白名单，不因来源/目标编号相同而删除合法连接。合法字母针脚保留，N-BAR/PE-BAR不套相邻排号，PE-BAR不误判为非PE。
- 补齐080C50、005C01两张真实目标图及5个补全正例，覆盖XD21:1、X21:5、X2:9、X2:11、N-BAR。现在5组初扫、9组补全（8正例/1负例）、10张图。坐标为手工整图归一化定位示例，非新模型输出。
- 补全每次仍选1例；v2评分在原理号/工作区基础上增加信号名一致+12、同工作区的来源/目标业务页一致各+4；不使用来源端子号评分。旧双图任务评分不增加这些项。没有新增最低分门槛。

## 边界

只修改ZH读取语义及相关适配；ABB1.1.4、XMZ0.1.2资源和双图配置保持，公共Graph拓扑/表格14列/图片预算/命令参数不变。新增引用证据为可选内部字段，Schema摘要随模型生成，不新增HTTP路由或数据库列。补全仍保留起点state与已有电流。

端点读错和漏检仍需真实模型验证。没有唯一PDF引用时无法修复初扫页号；初扫接收方向与重复段的Prompt修正不等于程序已经能判读箭头。没有把原来54条未定位任务报告成已修复，也未重新处理既有运行。
