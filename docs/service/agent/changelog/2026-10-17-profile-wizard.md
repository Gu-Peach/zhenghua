# 2026-10-17 Profile 三步创建 Agent

固定 classification/scan/completion 模板与实际提取 Schema。上传规范化图片后，VLM产生规则说明和Expected候选；候选与原图/请求/来源修订/模型用量持久化。表格修改后的JSON直接由程序校验并原子保存，模型不能自我确认。

拆分识别工作区/业务页号，项目名取PDF文件名。初扫跨页终点保持空值；补全从已确认初扫连接建立任务，明确区分原页与目标页，按用户标注的目标工作区/页号匹配，每连接一次有限图像调用；缺目标产生空终点负例，不猜补。用户可在分类/扫描步骤补充负例图片，仍要求正例/负例/跨页案例。

前序规则或答案改变使后续确认失效；Prompt有摘要封签，其他工具修改后须重新确认。阶段重建移除旧向导案例，避免旧任务答案混入新包；保存/生成重试均有版本与操作标识。旧独立对话/诊断工具保留，未新增其前端入口。

共享8100挂载Profile路由，8000注入可信用户，不信任浏览器的身份头。发布前内部导出校验包，由Server负责最终登记。Worker兼容本地与Storage包，重试只读任务冻结版本。

测试与部署状态以[跨模块交付](../../../changelog/README.md)及[执行计划](../profile-wizard-plan.md)为准。默认测试Fake VLM，不调用付费模型；未验证真实模型质量，未发布真实规则或重启8000/8100/Worker。
