# ZH 补全空响应与重复 N 线修正

## 行为

`zh_crop@2.2.1`沿用目标图列区域与原坐标/预算，初扫不改。修复`{}`在补入task_id/默认值后变成有效待复核结果、未进入校验重试的问题。ZH补全在默认值前检查end（可null或兼容旧end_*）、说明或非空视觉不确定性及任务身份；只返回任务号/状态、空包装或无说明的空终点将进入原本最多两次的Schema重试。明确end=null并说明匹配不唯一仍是合法回答，不为未知而强迫重试。

动态Schema和重试反馈同步；不新增定位/递归节点、整页重试或正常路径调用。两次仍无有效回答时，现有页循环继续，程序记录completion_state=failed、具体warnings和视觉原因，保留起点。合并未确认终点时同时保留uncertainties，避免图像歧义被丢失。公共状态枚举和业务数据库/API未扩展；ABB/XMZ不启用ZH响应语义约束，公共异常/不确定性合并修正适用于所有模板。

补全Prompt按目标图回指的来源工作区/业务页+完整信号名匹配，N/PE同号只辅助；区分references的目标地址和目标图的来源回指。对象位置有冲突但页号/信号唯一时保留依据和歧义，不能改选另一条同号线路。
