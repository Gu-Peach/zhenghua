# 2026-10-18 Explain重扫工具与原图/细节图适配

用户授权增加行、页与工作区重扫。Explain原工具循环新增`rescan_connections`，可信项目/批次/身份/附件来自当前会话，模型仅指定精确范围、all/start/end字段组和本次要求。返回租约任务，不以口述冒充候选；询问既有任务差异不重新启动扫描，公开回复显示后前端再显示任务卡。

执行由现有独立Worker进程并行领取新的重扫队列，不增加端口或生产BackgroundTasks。租约心跳、过期恢复、最多3次领取（含首次）、节点前后取消检查及模型/页检查点持久化。新增重扫故障不停止原提取消费者；首次PDF提取逻辑与规则资源未修改。恢复检查模型/图像配置指纹，不把不同输入配置混用为同一任务。

复用既有`ExtractionStageGraphClient`、页级Graph、扫描/补全器、Profile dispatcher与确定性后处理。候选session替换持久化边界，绝不调用`commit_simple_extraction`或发布正式行。已定位跨页终点复用冻结来源事实的补全，同页或引用未定位时经原页Graph重新扫描后按字段组裁剪；混合工作区分别处理并合并候选。冻结对端与扫描方向冲突时不猜测配对。工作区包括索引中的零记录页，不做Stage1重分类或目录迁移，新行归属亦取可信索引。

原规则优先读取原批次的冻结ZIP；无缓存时按历史key/version/checksum读取发布包或严格校验本地资源。原包缺失/校验失败不会回退最新版本。本地文件集合摘要、ZIP摘要与绑定摘要属于不同域，分别验证。原始图纸按需从私有Storage获取，恢复前校验已用图片摘要；历史页元数据以分页JSON投影读取，避免下载整批原始响应。

新增仅重扫使用的ModelGateway包装：保留原Profile的Prompt、Few-shot、Schema及裁剪/坐标回映，额外提供原始完整页、关联完整页和绑定的用户细节。全部辅助图随其原页一起送入，不把截图坐标当作原图坐标。请求指纹包含最终实际多模态消息，保存模型、耗时、重试、token用量、Profile与图像摘要；每行保留相关摘要与有限调用说明，完整调用记录在任务检查点。

匹配以所属物理页、原理号、端子和已有坐标保守确定；同分/重复归属不猜行ID，保留旧值并提示。新增仅在全页/工作区范围生成候选，未再次识别的旧行不自动删除。字段组不会覆盖未授权端点；复核由确定性程序计算，保留未处理端点的缺口。

验证使用Fake VLM、Mock HTTP和独立数据库，不调用真实模型或重扫实际项目。覆盖ZH、ZH裁剪版、ABB当前私有扫描契约的初扫+补全，以及终点补全；验证完整原图与辅助图实际进入模型输入、原Profile冻结失败、候选隔离、保守匹配及旧链路兼容。具体最终结果见[跨模块记录](../../../changelog/README.md)与[ADR-0034](../../../adr/0034-explain-rescan.md)。

使用需加载8000 API2.8.0、8100及现有Worker的新代码，并应用`20261018050000`；Worker启动指令不变。不会自动启动真实重扫或替用户确认。

最终验收：92项Agent（含ZH/裁剪ZH/ABB三种Profile的完整重扫、跨页终点、同页终点及旧提取链路）与18源码mypy通过。只使用Fake VLM，本轮不评价真实识别准确率；并行ABB资源改动保留，按其包是否启用私有扫描契约构造离线响应，未修改其规则。
