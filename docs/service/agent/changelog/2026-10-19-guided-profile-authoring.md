# 图像驱动的规则配置对话

按[ADR-0038](../../../adr/0038-guided-profile-authoring.md)沿用Wizard三阶段候选/确认，新增对话驱动的证据复用和阶段修正，不改提取Graph、现有正式Profile或项目绑定。

- 对话候选将当前阶段的处理链路、样图读取证据和可修改规则写入持久回答。模型Prompt要求说明标题栏定位、标记/箭头、沿线找端子、跨页引用/回指等公开依据，不输出内部思维过程。
- 手动分类图片最多4张，逐图生成独立Expected；后续初扫可复用已确认分类中的实际图片（包括PDF抽样图）。本轮新原图优先，不悄悄切回旧图。
- 用户要求修改先前阶段时，revision_stage受前序确认约束，重新生成候选并使当前及后续确认失效。补全冻结原图及起点，程序拒绝把来源图同时当目标图。
- PDF请求stage支持classification/scan/completion，PdfSampleInfo补缺省stage；抽样仅使当前阶段及后续失效，保留前序确认、原始历史。只保留两张随机样图（单页取一张），原PDF不保存，所用物理页号保留在样例上下文。
- 自动继续由Web在确认成功后发起独立轮次，沿用原服务的幂等/版本校验；无法确认目标仍需补图，不能自动接受候选或发布。

验证：39项Agent离线回归、5项Server接口回归通过，覆盖多图、PDF来源、前序确认、换图/修改、来源冻结、幂等和权限；PDF来源上下文补充后2项聚焦复验通过。5源码配置内mypy、7源码/测试Ruff、DTO/OpenAPI/TS导出和前端类型/lint/build通过；22项会话浏览器及最终7项定向复验（含2项登录/工作台）通过，去重24项。
