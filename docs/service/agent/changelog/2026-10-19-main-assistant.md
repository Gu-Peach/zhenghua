# 主助手运行时与专业 Agent 适配

本次实现 [ADR-0039](../../../adr/0039-main-assistant-orchestration.md) 的主助手首版。代码入口为 `services/agent/src/agent/main_assistant/`，挂载在现有 `extraction_main` 的 `/v1/assistant`，复用 ModelGateway、模型配置及内部鉴权，不启动新的端口或提取算法。

## 调用约定

- 主助手负责意图和受限工具编排，最多8轮，每轮最多6个实际工具调用。普通对话直接回答，专业 Agent 的单次回答不再交给另一轮模型改写。
- 业务工具由8000的受信 Facade 执行。8100接收不进入模型消息的临时 turn token，Server按持久轮次反查用户，并重新检查对象权限。用户、SQL、文件路径和任意URL不在工具参数中。
- 主助手没有提交线表、确认候选或发布规则的工具。导航、任务和提案事件只能来自真实业务回执。
- Explain调用关闭 `allow_rescan`、`allow_edits`；只读轮次同时隐藏并拒绝修改工具。零记录范围仍可从实际图纸索引获取最多4张来源图，不把没有线表等同于没有接线。
- Explain接收绑定规则的有限节选及版本/摘要，明确节选范围；完整规则归因由Profile的文件读取和图片工具执行，不声称还原当时模型内部推理。
- Profile先导入原任务冻结包的只读诊断副本，保留原版本；只读副本不能提修改、手动编辑、确认或发布。规则修改基于数据库最新且本人有权编辑的版本生成真实proposal；不直接应用。
- 已发布不完整包进入编辑器后，缺初扫起点继续沿用既有warning政策；结构、确认和并发检查仍生效。

## 运行与验证

沿用原有8100启动命令和模型配置。回调地址读取既有 `AGENT_SERVER_BASE_URL`，默认 `http://127.0.0.1:8000`；内部鉴权与Server的Agent凭据保持一致。8000与8100都需加载本次代码。

Agent测试分批累计162项通过：Explain全部单元、主助手、Profile编辑/校验/运行时/API，包含服务鉴权、工具白名单、零记录看图、只读历史副本及导出版本递增。修正一项旧测试固定断言ZH2.1.2的问题，改为断言当前来源版本的patch递增。测试全部使用Fake Gateway/MockTransport，无付费模型、真实重扫或实际规则发布。

主助手普通答复以公开delta输出；目前会等本次网关回答完成再分块传输，子Agent内部细粒度事件不逐条转发。重扫长任务独立执行，聊天只等待入队回执。
