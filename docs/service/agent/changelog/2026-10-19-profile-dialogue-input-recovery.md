# DIALOGUE_INPUT_INVALID恢复

上传两张原页/目标图后，模型内部决策ready=true但漏description或source_image会在生成交接前抛DIALOGUE_INPUT_INVALID，界面呈现空回答和同轮重试。真实test草稿只读确认两张附件已保存、无候选，失败模型原文没有保留；已离线复现该缺项路径。

修复在实际图像和用户输入的范围内恢复读取说明，不补造Expected；补全先恢复冻结来源，确实缺来源时持久化追问。首次失败后恢复会话可复用已有图片，后续澄清不丢图片上下文。Prompt补充ready=true必须给出读取说明，日志只记录缺项字段、阶段和数量。
