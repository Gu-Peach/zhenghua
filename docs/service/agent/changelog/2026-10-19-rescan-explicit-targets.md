# 指定目标页的终点重扫

## 问题

实际零候选轮次只做一次PDF52扫描，识别9条起点，但引用将位置代号误当工作区，目标目录匹配失败。用户目标页只在instructions，旧目标为空时Worker退回初扫，端点仍空而无字段变化。细节图确有传入，按保存配置重建保留768×739，但预算层把它当Few-shot，存在被删减风险。

## 实现

按[ADR-0041](../../../adr/0041-rescan-target-bindings.md)新增RescanRequest.target_bindings，逐组connection_ids绑定原样业务页，可附工作区/PDF页消歧，仅用于fields=end。主助手同样支持。工具Prompt要求用户给页时填写绑定，不扩写002M03为33/34/35。

Worker在任何模型调用前检查绑定属于baseline、目标在任务项目目录唯一。显式页优先旧目标，兼容可信原目标/唯一结构化引用。未知/重名/越界绑定安全失败；终点重扫直接遍历冻结baseline（含同页），不回退初扫。候选按可信原ID对应，起点/所属页/工作区保持；不再自动附带baseline旧目标图干扰单条任务，错页坐标拒绝。单条模型/Schema错误继续其他行，逐条warnings/unmatched_ids提示；已定位页和未识别端子分别保留。

预算函数可指定实际输入消息位置，重扫整页/主目标图/细节图全部受保护，优先缩减Few-shot，必要时缩小实际图。追加纯文字任务不会让真实图被当样例；指标保存输入尺寸。rescan_input_contract=3、缓存rescan-v6隔离旧产物，普通提取默认预算不变。

## 验证和启用

先补7项失败回归复现，再覆盖9行绑定两页、引用兜底、未知/重名/越界/冲突、失败继续、错页坐标及图片预算保护。同页端点夹具改为直接completion响应；无目标时零模型调用并有缺口，不静默成功。

185项默认回归通过、51项显式集成跳过；19项不同浏览器检查分批通过，含桌面/窄屏登录及工作台截图。恢复测试原先依赖被并行界面调整的旧标题，改按稳定任务region断言后通过，未修改该产品界面。类型/lint/build、Ruff、8个Agent源码/Server工具mypy及OpenAPI一致性通过。

实际已保存9行、原图/细节图/规则包只读下载并Fake重放：5条到002C11/PDF53、4条到002M03/PDF56，9次保留细节图、零初扫、9条候选不含起点修改。没有真实模型请求或业务写入，仅证明路由/契约，不保证实际端点识别准确率。
