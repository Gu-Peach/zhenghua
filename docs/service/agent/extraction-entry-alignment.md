- 以脚本现有文本为基准，将“不提取色标”的前缀和color=null后处理移到共享Graph Client；脚本继承共享处理，不再保留专属提取逻辑。前缀保持逐字一致且不重复追加。
- 平台根据已分类索引提供与脚本相同的DrawingPageInput身份信息；分类阶段尚未有索引时仍保留原渲染路径回退。来源/目标业务页与物理页严格区分。

- 核心页Graph、接收端过滤、定向补全、归一化及复核规则继续共用，不通过修改Prompt或强制非空来掩盖差异。过滤前后数量以独立诊断保存，区分模型无连接与全部为接收端；不发送诊断字段给VLM。

- 新任务使用新契约。旧任务已经保存的成功页/模型结果不自动改写；契约不符时明确要求新任务，避免普通重试混用新旧请求。冻结规则包机制保留，确保可追溯。
