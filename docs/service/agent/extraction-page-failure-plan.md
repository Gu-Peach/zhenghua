## 行为与恢复契约

- 仅隔离初扫已捕获并标记 `scan_failed` 的单页错误；不扩大现有异常捕获范围。配置、权限、持久化、租约和取消仍立即中止。
- 失败页不执行连接规划、补全或完成保存，不进入 `processed_pages` 或 `page:<number>` 完成缓存。有效页可继续引用其已渲染图片。
- 平台复用现有 `scan` 事件，页面状态为 `failed`，错误写入独立尝试产物；不增加数据库 Schema、公共 API 或状态枚举。本地写入独立失败尝试 JSON。
- 后续页照常发布和缓存。全部遍历完仍存在初扫错误时，以既有失败终态和明确“其他页面已处理”摘要保留重试入口；不伪报全部成功。
- 恢复复用成功页，失败页重新扫描；错误尝试历史保留。业务 Prompt、模型请求和输出字段不变，不自动重启服务或重跑现有任务。
