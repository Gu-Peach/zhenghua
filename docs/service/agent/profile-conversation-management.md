# 规则配置会话管理

保存的规则会话允许用户确认删除。删除仅作用于草稿入口，不删除已发布规则、项目绑定或提取结果。草稿文件和历史修订保留供诊断；不承诺物理擦除附件。

采用草稿 metadata 中的 `deleted_at` 墓碑，沿用 SQLite 事务，不改变已有表结构。列表过滤墓碑；所有读取和修改均通过所有者检查并拒绝已删除草稿。删除事务核对修订号，防止误删另一窗口更新的会话；重复删除对同一所有者幂等。已启动的请求不能将删除的草稿重新写回。

公共 API：`DELETE /api/v1/profile/drafts/{draft}`，请求体 `DraftDeleteInput { revision: 正整数, confirmed: true }`，成功返回204。Server 使用登录身份转发至 Agent，禁止客户端指定所有者；403/404/409保留稳定错误语义。

界面通过自定义下拉列表展示保存的会话，每行有独立的打开和删除按钮，无需恢复后再删除。确认后复用删除API；成功移除该行，删除当前会话时回到新对话，删除其他会话时保留当前会话及输入。取消和失败均保留状态。列表支持键盘、Escape/点击外侧关闭及窄屏长名称。上传PDF和图片仍为发送按钮左侧两个带名称/提示的图标按钮，原阶段约定保持。
