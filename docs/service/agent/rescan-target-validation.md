# 显式目标页与源工作区隔离

2026-10-20，修复设计：`scope.workspace_code`限定原连接范围；`target_bindings[].workspace_code`仅限定目标页，不能继承源工作区。完整业务页号可跨工作区，模型不确定目标工作区时省略可选条件，并先按业务页号检索项目图纸目录。

修复在入队适配器完成授权后，按项目当前完整目录提前校验每个目标绑定，冲突反馈实际候选的业务页、工作区和PDF页，供同轮模型修正后再创建任务；不静默删掉显式约束、不修改业务页号或猜测目标。Worker复用同一纯函数，在冻结目录再次检查，继续保留范围/重复行保护。真正歧义仍拒绝，PDF/工作区限定必须满足。

不修改旧失败任务的请求、冻结输入和状态；不自动重新调用真实模型。Prompt及工具参数说明强调分别检索源范围和目标目录。本次不改Profile、线表字段或公共DTO/API。
