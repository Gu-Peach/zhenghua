2026-10-16，基于用户003.C/004.C本地复测及原图核对，实施本地ZH2.1.1。仅修改提取规则和相关适配，不运行测试/模型，不写数据库、不覆盖已有结果。

## 契约

1. 初扫仍先定位放线标记，分段只读最近端点，再判断同段箭头；按一个实际放线段输出一次。引用按工作区、对象位置、斜杠后的业务页/列分别读取，raw保持字面，不拼接对象尾部数字。不能靠猜测把8改1或31改1。
2. ZH目标图补全上下文升级v2，只传来源业务身份、来源元件元数据、原理号、信号名、绑定引用、电流及目标页身份。起点完整端子与坐标留在state，真实请求及Few-shot均不发送。旧v1上下文进入适配器时投影到v2；ABB/XMZ和旧双图模式保持。
3. 补全Prompt使用匹配对端回指线路→沿线向页内到最近目标接点→分别读取接口与针脚→组合完整端子→读取该目标接点坐标的顺序。080C50回指位于页底且箭头朝外，不能强制只找入页箭头；补全沿用任务归属，不重新定向。母排用实际N-BAR/PE-BAR，功能文字与接口名均不能代替针脚。未读出针脚时留空复核，不生成X2:X2。
4. 案例选择适配v2任务的信号名、来源/目标业务页；仍只选一个，不将全部新增案例发送。初扫案例不改变数量策略。
5. 图像expected补入不同柜体同排端子编号不同、模块接口X21/X2及N-BAR的正例，保留不唯一匹配负例。初扫沿用五组图像案例中的接收段/直接放线段说明，Prompt强化不反向输出接收段、不重复穿越端子的读取方法，不增加每次初扫图片数。模型结果只做语义完整性校验，不新增端子前缀白名单，不以端子编号相同为由删除合法连接。

确定性补救只接受图纸索引中的明确证据；无法确认仍留空，不根据“目标不存在”自动替换工作区/页号。已有电流与起点state保持，结果表列不变，图片预算不在本轮调整。

本地图纸索引已核实保存了003C02/003C08及004C06的正确引用。目标未解析时，只在同一来源物理页、相同工作区身份和对象标识下存在唯一地址候选且目标页可用时恢复；同址多次出现可合并，多个地址仍待复核。工作区缺点的格式仅用于与PDF候选比较，不直接猜测目标。新增可选references.source_index_raw保留PDF依据，raw仍保留模型文本；两者冲突时补全使用已核对的地址字段。
