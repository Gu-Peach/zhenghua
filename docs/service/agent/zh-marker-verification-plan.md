# ZH初扫定位与跨页区域核读

2026-10-22，用户要求结合002.C/003.C/004.C真实端子特征优化本地Prompt，并试加来源跨页标记区域放大校验。仅agent_test，计划版本2.6.0；替代2.5.0“无来源局部核读”的实验约定。

## 契约

- 初扫整页，同时读放线段、最近两侧端点、原理号、引用类型及出页箭头连同地址文字的整页归一化包围框marker_region。即便地址读不清，也保留可定位的候选引用raw=null；不增加独立locate调用。
- 初扫后、方向过滤与跨页任务构建前，按Profile开关执行来源区域核读。只处理缺终点的出页/不确定候选；不重读已确认同页两端或接收段。
- 40%定义为整页宽、高各40%的最小窗口（面积16%，相对整页同显示尺寸约2.5倍）；按全部候选区域分组，能容纳的同窗批量读，分散者分窗。超出窗口的单个地址框按需扩展到包含完整框与边距，边缘平移保宽高。从原始页图裁剪，再按现有模型像素预算缩放，不放大低清整页缩略图。
- 每个候选使用程序生成的稳定ref_id，核读仅返回该ID的引用类别、字面地址、完整信号及图像依据。不得新增连接、改起点/原理号/已确认终点。看到本地端子挡在箭头之前时否决该引用、留待复核，不编造新的端点。
- 缺坐标、框外/跨窗、重复或丢失ID、无依据、核读失败/未读清均不得用未校验地址跳页。模型不能自报verified；由程序绑定响应、保存原值和审计证据后设状态。原始响应日志与每窗原图裁剪/输入/结果保留，失败不影响其他窗口和页面。
- 核读通过后按字面工作区/对象/业务页/列构建索引；禁止异常前缀解析失败后悄悄截取地址后缀回退当前工作区。目标仍整页、单连接、按原理号和回指追线遇最近端子即停。

## 端子特征

观察002C03/11、003C01/02、004C01/04：排号与接点编号、元件实际引脚、插座接点及带文字母排是端点；柜框/位置文字、普通节点、跨越无节点导线、元件关联页表是上下文。`-FC11`、`-XA`、`-S11`等标签须与实际接点绑定，不能只凭标签终止追线。共享排号可沿同一排继承，不能跨柜体或越过最近端子。
