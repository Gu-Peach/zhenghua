# ZH2.7.0来源复查与路径校验

2026-10-22，依据2.6.0实测问题修改agent_test。正式服务与API/数据库契约不改。

## 范围与边界

- 来源局部核读不再接收initial_raw/initial_signal/initial_path，不返回规范化raw或工作区字段；只逐块抄录图中文字和选择地址/信号块索引，由程序从选中的原文生成引用。仅字面解析，禁止补入=M等原图没有的前缀。
- 局部核读之后，对未确认跨页、缺框/非导线引用、地址语法无效或没有有效引用且缺终点的来源连接做整页复查。按稳定candidate_id分批，每批最多8条；起点整个对象与原理号不变，已确认终点不变。必须确认冻结起点对应同一实际端子，否则标记来源冲突，不换端子。可补本页end，或重新定位真实跨页引用；新引用仅再核读一次，不无限循环。目标页索引不存在的合法字面地址仍保留未定位，不靠目录猜字。
- 同页复查输出源端点到最近终点的整页路径；复扫输出匹配回指到最近终点的路径。路径点必须在图内、完整覆盖拐点，端点贴合实际端子坐标；禁止把跨线无节点交叉或其他回路当连接。字段门禁只能检查几何/结构，不等于像素连通性证明。
- 对目标页候选终点增加独立整页连通性复核，仅确认或否决，不能替换端子；使用冻结来源/回指和候选终点，先独立追线，不复述上一轮说明。未确认则清空候选end/nearest_terminal并保存复核原因。每个有候选终点的任务最多一次复核（Schema重试沿用现有上限）。若目标页仍到达延续箭头则保存continuation_references并待复核，不强塞无关端子，也不自动递归跨多页。
- 明确电压/频率标签如380VAC/24VDC/60Hz不允许作为端子；清除该无效身份并留复核依据，不把相邻端子猜回来。合法2A等针脚和N/PE母排保留。
- Profile配置控制新流程与路径门禁。失败诊断、原始模型响应及来源复查前后快照保存；核读/复查/复核在批次边界检查取消。
