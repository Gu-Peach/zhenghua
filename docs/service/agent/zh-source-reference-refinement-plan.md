# agent_test ZH来源引用精读与目标整页补全

2026-10-22，用户授权仅改agent_test提取Agent，延续不运行验证/测试/真实模型、用户自行实测的约定。正式Agent、API、数据库包、其他Profile及历史结果不变。

## 链路与边界

整页初扫 → 来源引用区域定位 → 原始高清图片裁取/引用精读 → 程序解析和核对地址 → 创建跨页任务 → 目标整页定向补全 → 校验保存。新增节点位于scan_source与plan_references之间；按Profile资源配置启用，无品牌硬编码分支。

冻结初扫起点、起点坐标、原理号、方向与连接集合；精读只修改引用及有图像依据的完整信号名。同页连接不重扫。目标整页只补当前指定连接，不提取无关目标页线路，不递归创建连接。

## 本地结构化契约

- DrawingReference增加来源整页归一化reference_region；程序专用source_reference_evidence记录初始/精读/文本原文、区域、确认或未确认状态及依据，隐藏于模型Schema且不信任模型提交的该字段。
- 引用定位与精读采用独立Pydantic DTO，绑定唯一reference_id。定位返回区域，不返回业务修订；精读返回图面原文/信号及依据，不允许修改来源端点或生成物理页。
- 定位优先初扫区域或来源PDF文字坐标的唯一明确匹配；不足时整页定位。精读从原始页面图片裁取，补边涵盖箭头/文字，局部图只缩小、不从低清图插值放大。同一重叠区域可合并读取，多条任务按ID逐项核对。
- PDF文字只在来源已定位区域内核对；唯一有效原文可纠正读数，存在冲突/多义不能猜最近页或仅以目录存在替换。没有文字层时保留图像精读依据。无法定位/读取/解析的引用阻止错误补全，保留初始事实和原因。
- 目标物理页仅由已分类索引中唯一业务身份决定，不接受模型物理页号；验证业务工作区/页号对应，页列分离且ZH列限0～9。

## 实现与持久化

引用精读通过本地stage dispatcher/Graph client适配，使用现有模型Gateway/TraceStore。页级产物保存更新后引用及计数；局部图/定位与读取诊断落在该运行独立目录，失败不覆盖起点。新增模型操作使用独立stage/item_id，Profile版本与图像摘要参与现有缓存；运行取消在精读批次边界检查。完成页仍在所有步骤后保存。

关闭ZH completion_view.enabled，目标补全按整页坐标输出；输入长边与总像素预算不提高，日志保留实际发送尺寸。来源精读新增调用将增加耗时，不承诺质量或费用。现有3目标图/4正例保持，不新增未经人工确认的Expected；引用精读首版使用Prompt和Schema，不伪造已确认的新Few-shot。
