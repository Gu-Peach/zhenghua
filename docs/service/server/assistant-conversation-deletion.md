# 主助手历史对话永久删除

2026-10-19，根据用户要求，历史列表每条对话提供×，点击直接请求数据库永久删除，不要求先恢复该会话。

## 契约与数据边界

- 新增 `DELETE /api/v1/assistant/conversations/{id}`，成功204、无响应体。只允许所有者删除，已删除的同一ID重试也返回204；其他所有者会话返回404。未登录401。
- 删除会话及级联的turn/action/attachment元数据；不删除线表、项目、Profile或独立重扫任务。未确认方案随会话入口移除；已发起的独立任务或已提交业务修改不因删除历史被撤销。
- 数据库RPC锁定会话，与 `assistant_begin_turn` 使用同一行锁；有未过期的运行轮次或最近20分钟内未完成的附件上传时返回409，先完成/停止后再删。过期轮次可删除，旧工具令牌随后失效。
- 同一事务将会话专属Storage路径写入清理队列再删除元数据。Server尝试清理；暂时失败保留队列，后续删除或历史列表请求重试。路径仅限 `assistant/{owner}/{conversation}/{attachment}/...`；不删除共享项目或规则资源。
- 清理队列只允许service_role访问，带owner/会话索引、稳定主键、时间戳与路径约束；与原业务表无反向级联。
- 前端成功响应后移除列表条目。删当前会话回到新对话，清除对应本地恢复ID；删其他会话保留当前输入和附件。失败保留列表和内容，可重试；进行中操作禁用重复点击。
