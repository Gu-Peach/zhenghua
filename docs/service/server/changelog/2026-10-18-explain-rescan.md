# 2026-10-18 重扫附件、租约任务与确认事务

新增`connection_rescan_assets`与`connection_rescan_runs`及service-role RPC，RLS限定项目所有者与创建者。浏览器仍只请求8000，Agent/Worker共用8100宿主与原Worker进程。API2.8.0，生成DTO/OpenAPI/TypeScript同步，无新增环境变量。

`POST /api/v1/projects/{project}/rescan-assets`上传JSON Base64辅助图，绑定会话、物理页与source/target用途。校验PNG/JPEG/WebP、8MB、2000万像素，先检查图片头再解码并规范成PNG。使用已有PyMuPDF，无新图片依赖。元数据先登记为未上传，文件完成且权限仍有效才置就绪；失败可原ID重试，未就绪附件不能入队。截图为项目私有文件，不进入规则草稿或公开目录。会话移除只取消本轮选择，文件保留至项目删除，供已确认修订追溯。

`GET .../rescans`、`GET .../rescans/{run}`读取任务/候选，`GET .../{run}/evidence`提供授权签名图（最多8张原图及绑定截图）。普通任务读取不暴露原始baseline、租约token、私有资源路径或完整检查点。`POST .../{run}/cancel`取消待执行/执行任务；`POST .../{run}/decision`只接受checksum/accepted，不接受客户端补丁。

创建任务原子冻结完整范围/行版本/图纸索引/Profile。确认事务检查所有者、批次、索引、完整范围、版本与24小时期限，任一冲突整批拒绝。已有行更新不改ID、所属页、工作区和批次；新增行必须属于原预览范围。白名单和端点字段组在SQL再次检查，坐标/关联页必须属于项目。重读相同接点时保留明确重新确认的坐标，避免旧失效触发器误清空；版本以事务返回值为准。

提交保存before/after与新重扫证据，原提取证据保留为历史，复核由程序决定。重扫候选不存在自动删除操作。删除行时清除包含该行的重扫任务副本，防止残留候选复活；其他业务行不删除。删除项目会阻止活动重扫，并将已登记的辅助文件纳入既有先归档、清Storage、再删数据库的一致性流程。
