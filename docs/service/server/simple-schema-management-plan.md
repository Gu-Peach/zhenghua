## 契约

- 项目仅所有者可操作，来源PDF及图纸页索引放extraction_projects；规则引用在extraction_profiles，结果在extraction_connection_rows。禁止活跃数据管理路径查询已删除旧表。
- 工作区/图纸ID由项目和索引内容稳定派生，不伪造分类页码；索引为空显示未处理状态。图纸签名URL只对经项目权限核对的稳定对象路径生成。
- 批次替代结果版本/线号单元，API显式返回batch_id；列表按来源PDF物理页/row_order/id排序，原理号不作为唯一键。行编辑依据record_version，事务保存before/after与幂等回执到项目索引的管理元数据，不新增审计业务表。
- PDF上传只校验、保存私有对象并登记项目；不调用Agent，不伪造处理进度。规则引用从受限的本地Profile目录登记，保留key/version/checksum/resource_ref；远端资源编辑及规则自完善不在本轮启用。
- 项目删除先归档并核对更新时间，清理项目命名空间Storage对象后删除数据库行；失败保留可重试归档状态，绝不删除别的项目资源。
- API公共DTO与前端生成契约一起更新；旧纠错/候选/自动提取入口明确返回未接入，不继续查询已删除表。
