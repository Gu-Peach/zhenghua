# 电气原理图放线表提取需求说明

## 1. 需求目的

本需求用于从电气原理图 PDF 中自动提取放线表所需信息，并形成结构化结果，供后续前端展示、人工校验和 XLSX 导出使用。

系统需要根据图纸中的放线标记，定位对应的起点端子和终点端子；对于终点位于其他工作区或其他业务页的情况，根据跨页引用定位目标图纸并补全连接信息。

最终每条记录至少应包含以下字段：

| 字段 | 含义 |
| --- | --- |
| 原理号 | 当前连接所属的原理图编号或原理号 |
| 端子排 | 起点或终点所属的端子排 |
| 起点元件 | 连接起点的元件标识 |
| 起点端子 | 连接起点的端子编号 |
| 终点元件 | 连接终点的元件标识 |
| 终点端子 | 连接终点的端子编号 |
| 电流 | 图纸中明确标注的电流值；没有明确值时留空 |
| 来源页 | 该记录对应的 PDF 物理页号及图纸业务页信息 |
| 状态 | 已确认、待补全或需要人工复核 |

## 2. 图纸信息定位

图纸中的业务定位信息由以下内容组成：

- `Plant Function`：工作区，例如 `006.M`、`006.C`、`082.R`。
- `Page Number`：当前工作区内的业务页码。不同工作区可以重新从 `1` 开始编号，因此不能只使用数字页码作为全局唯一标识。
- `Object Loc.`：元件在图纸中的对象位置或元件标识，例如 `+01F26`。
- PDF 物理页号：PDF 中从 1 开始的实际页序，用于追溯原始文件。

图纸唯一定位建议使用：

```text
(Plant Function, Page Number, Object Loc.)
```

PDF 物理页号仅作为来源和回查信息保留，不能替代工作区与业务页码。

> [图片占位符：图 2，图框中 Plant Function、Page Number、Object Loc. 的位置]

## 3. 放线标记识别

放线标记是建立连接关系的入口。处理图纸时应先识别放线标记，再沿标记查找连接两端的信息。

放线标记可能出现在：

- 起点端子附近；
- 终点端子附近；
- 连接线或端子说明区域；
- 指向其他图纸的跨页引用位置。

识别结果需要保留原始文本或标准化后的标记，便于后续复核。模型只能依据图中可见内容提取，不得根据常识补造不可见的终点、元件或电流值。

## 4. 起点与终点判断

### 4.1 起点端子

起点端子以图纸上明确出现的端子标识为准。当前规则中重点关注以下端子系列：

```text
XD0
XA
XD10
XD11
XD12
XD21
XD23
XD22
XD24
XD3
XD5
XD4
XH
```

上述内容是端子标识。放线表中的端子排是另一层信息，不能把端子排名称误识别为端子。

当前端子排映射关系如下：

| 图中端子系列 | 放线表端子排 |
| --- | --- |
| `XA`、`XD10`、`XD11`、`XD12` | `X1` |
| `XD21`、`XD23` | `X21`、`X23` |
| `XD22`、`XD24` | `X22`、`X24` |
| `XD3`、`XD5` | `X3` |
| `XD4` | `X4` |
| `XH` | `X5` |

端子排属于归一化输出字段，不能反向改变起点端子的原始识别结果。

### 4.2 终点端子

终点端子分为两种情况：

1. 终点和起点位于同一张图纸中，直接从当前图纸读取。
2. 终点通过跨页引用指向其他工作区或业务页，需要先解析引用，再读取目标图纸中的终点元件和终点端子。

如果目标位置在图中不可见或无法确认，终点字段保留为空，并将记录标记为 `needs_review`，不能使用推测值填充。

> [图片占位符：图 3，同页起点到终点的放线连接]

## 5. 跨页引用解析

跨页引用通常包含工作区、对象位置和业务页/列位置信息。例如：

```text
=.C+01F26/1.4
```

该引用的解析方式为：

| 片段 | 含义 |
| --- | --- |
| `=.C` | 跨页引用标记及目标工作区后缀信息 |
| `+01F26` | 目标对象位置，即 `Object Loc.` |
| `/1` | 目标工作区内的 `Page Number` |
| `.4` | 目标图纸中编号为 `4` 的列或定位区域 |

实际目标工作区需要结合图纸上下文和图框信息确定。例如目标页位于 `006.C` 工作区时，该引用应定位到：

```text
Plant Function = 006.C
Page Number    = 1
Object Loc.    = +01F26
Column         = 4
```

用户提供的 PDF 示例中，跨页终点位置在 `082.R` 工作区、业务页 `1` 的编号 `4` 列。引用中的列号必须按图中实际编号读取，不能将列号当作从零开始的数组下标。

跨页处理流程：

1. 识别当前页的放线标记和起点端子。
2. 从标记中读取目标工作区、目标业务页、对象位置和列位置信息。
3. 在目标工作区目录中找到对应 `Page Number` 的图片。
4. 在目标图片的对应列或对象位置查找终点元件和终点端子。
5. 将起点与终点合并为一条放线表记录。
6. 保存原页、目标页、原始引用和解析结果，便于人工回查。

> [图片占位符：图 4，跨页引用及目标页定位示意]

## 6. 分阶段提取流程

### 阶段一：PDF 拆页与工作区归类

输入为原始 PDF 文件。

处理步骤：

1. 按页渲染 PDF，建议分辨率不低于 300 DPI。
2. 为每张图片保留 PDF 物理页号。
3. 读取图框中的 `Plant Function` 和 `Page Number`。
4. 将同一 `Plant Function` 的图纸归入同一个工作区目录。
5. 图片名称使用业务 `Page Number`，同时保留物理页号映射，避免不同工作区中页码重复造成混淆。

建议目录结构：

```text
project/
├─ source.pdf
├─ images/
│  ├─ 006.M/
│  │  ├─ page-001.png
│  │  └─ page-002.png
│  ├─ 006.C/
│  │  └─ page-001.png
│  └─ 082.R/
│     └─ page-001.png
└─ manifest.json
```

`manifest.json` 至少记录：

```json
{
  "pdf_page_number": 3,
  "plant_function": "006.M",
  "page_number": "1",
  "image_path": "images/006.M/page-001.png"
}
```

### 阶段二：逐图扫描与连接索引

阶段二按工作区和业务页顺序扫描图片，提取当前页所有可见信息：

- 原理号；
- 端子排；
- 起点元件和起点端子；
- 当前页可直接识别的终点元件和终点端子；
- 放线标记；
- 跨页引用；
- 电流；
- 来源工作区、业务页和 PDF 物理页号。

本阶段建立连接索引。每个连接单元建议至少包含：

```json
{
  "wire_number": "0272",
  "source": {
    "plant_function": "006.M",
    "page_number": "1",
    "pdf_page_number": 3,
    "component": "+01F11.3",
    "terminal": "XD3:3"
  },
  "local_endpoints": [],
  "cross_page_references": [
    {
      "raw": "=.C+01F26/1.4",
      "target_plant_function": "006.C",
      "target_page_number": "1",
      "target_object_loc": "+01F26",
      "target_column": "4"
    }
  ],
  "current": null,
  "needs_cross_page_completion": true
}
```

本阶段不应将无法确认的跨页终点当作已完成数据。跨页字段可以先保留引用和目标定位元数据，等待阶段三补全。

### 阶段三：跨页定向补全与最终表格生成

阶段三只处理阶段二明确产生的跨页任务。每次调用只提交：

- 当前连接单元的元数据；
- 当前起点信息；
- 一张目标页图片；
- 目标列、对象位置和原始跨页引用。

阶段三需要从目标页中读取：

- 终点元件；
- 终点端子；
- 目标页原理号；
- 目标页端子排；
- 图中明确出现的电流值。

阶段三不得修改阶段二已经确认的起点端子，也不得处理未被任务指定的其他连接。

最终输出为结构化表格数据，前端根据该数据生成 XLSX。每行都必须能追溯到原始 PDF 页和目标图片。

## 7. 电流字段规则

电流必须作为独立字段提取，不能由电压或元件类型推算。

- `24VDC`、`110VAC` 等属于电压或供电信息，不应写入电流字段。
- 只有图中明确标注的电流值才写入 `current`。
- 图中没有明确电流值时，`current` 保持空值。
- 电流位于目标跨页时，由阶段三读取；若目标页也没有明确电流，则保持空值并记录复核状态。

## 8. 结构化结果示例

```json
{
  "wire_number": "0272",
  "principle_number": "<图中原理号>",
  "terminal_block": "X3",
  "source_component": "+01F11.3",
  "source_terminal": "XD3:3",
  "target_component": "+01F26",
  "target_terminal": "<目标列中读取的端子>",
  "current": null,
  "source_location": {
    "plant_function": "006.M",
    "page_number": "1",
    "pdf_page_number": 3
  },
  "target_location": {
    "plant_function": "006.C",
    "page_number": "1",
    "object_loc": "+01F26",
    "column": "4"
  },
  "reference": "=.C+01F26/1.4",
  "status": "completed",
  "needs_review": false
}
```

## 9. 验收要求

### 字段准确性

- 原理号、端子排、起点元件、起点端子、终点元件、终点端子和电流字段位置正确。
- 端子与端子排不混淆。
- 不把电压值填入电流字段。
- 不能从图中确认的字段为空并标记复核。

### 连接准确性

- 同页连接能够正确关联起点和终点。
- 跨页连接能够根据放线标记定位目标工作区、业务页、对象位置和列号。
- 业务页码重复时，必须同时使用 `Plant Function` 区分目标页。
- 不能因为页码顺序相邻就默认两页属于同一连接。

### 可追溯性

- 每条记录保留来源 PDF 物理页号。
- 跨页记录保留原始引用文本和目标页信息。
- 阶段一、阶段二和阶段三均输出可诊断的 JSON 产物。
- 最终表格能够回查到原始图片。

### 异常处理

- 模型返回非法 JSON 时重试，仍失败则保留错误信息并继续其他任务。
- 找不到目标工作区或业务页时，记录为 `needs_review`。
- 目标页图片过大或模型超限时，单任务降级或重试，不影响已完成任务。
- 任务中断后可从阶段 checkpoint 继续执行。
