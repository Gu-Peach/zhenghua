1. 主agent接收到用户的纠错信息
   主agent的思考
2. 主agent调用二三阶段agent修改数据
3. 每一阶段的agent在执行是主agent给出反馈xxx正在执行
4. 二三阶段agent返回修改后的数据存放至数据库中
5. 主agent告诉用户已处理完毕

7. 主agent告诉用户已处理完毕
