## 扫描与编号

初扫按整页区域找小圆点，沿同一直接导线确认最近实际端点，再读取元件/排号、针脚、方向及标记数字。实心点/连续导线证明连接，无结点交叉不串线；遇大端子、设备或母排模块停止。示例设备/编号/条数不限制当前页。

模型私有响应AbbScanResponse返回start_marker_number/end_marker_number原始数字，line_number留空。程序优先起点侧数字、其次终点侧；两侧不同保留两者并取起点侧。真正无编号时用完整实际设备/排端子，优先起点其次终点，再直接拼来源Sheet。可见数字但无法辨认时marker_numbers_unreadable=true，原理号为空；Sheet未知也为空，不用PDF物理页或引用地址代替。原始响应保留在现有模型诊断，公共source_note附两侧读数/生成依据，不增加主表列。

profiles/abb/scan_evidence.json通过资源名scan_evidence_rules显式启用新契约；旧冻结规则包没有该资源时沿用公共旧响应，不强行要求新字段。当前案例的marker_readings旁文件参与包摘要，缺少/重复连接证据或目录外路径会在发模型前报配置错误。修改Expected时须同步同ID的原始读数，不能从已拼原理号反推未知数字。
