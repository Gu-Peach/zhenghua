# ABB Stage 2内部：定向跨页补全（1.1.4）

只补task指定的一条连接。提供来源图和目标图时共同核对；只有目标图时以冻结task的来源信息为准。只输出CrossPageCompletionData JSON。

1. 用/Sheet.数字列字母行、电位身份及目标回指匹配线路。/241.1A是Sheet241列1行A，/205.3D是Sheet205列3行D，不是针脚。Sheet为业务页，不能用Cont或PDF物理页替代。
2. 沿对应入页线路到第一个实际端子，遇到大圆圈端子或设备端子即停止。小圆圈是放线标记，不是端点；同段第二个小圆圈不能导致再生成一条连接。
3. 保留来源起点、方向、来源Sheet和已按数字/完整端子直接拼Sheet生成的原理号。目标页编号不重新拼接，不改成引用坐标或电位名；目标图框功能可以与源电位身份不同。
4. 读取目标位置、元件、描述和实际针脚，不从外部表、地址或教学标注补值。例如LV12/241上=LV11-Q4 L1回指/205.3D的线路接到+EH.Q21的-Q1:2。
5. 目标不在图册、候选不唯一或针脚不清楚时，保留已确认字段，未知字段为空，needs_review=true、status=needs_review，不阻塞后续。只有触点旁关联地址不代表实际出页线。
6. 不扫描其他连接，不把蓝斜杠作为排除已指定连接的依据。无直接证据不补电流，已有电流由上层保留。

## 端子图片坐标

每个可见start/end填写terminal_coordinates={"x":0.2,"y":0.5,"pdf_page_number":1}，记录实际端子符号或连接点中心。以整张图片左上角为(0,0)，向右x、向下y增大，分别除以整图宽高归一化到0到1；等比例缩放不改变归一化位置。不能填放线标记、文字或箭头坐标，不按编号或外部表推算。端子未知或无法定位时为null。

初扫同页可见两端使用当前输入图片的PDF物理页号；跨页end仍为null。内部补全仅读取目标实际端子坐标，使用目标图PDF物理页，保留来源起点坐标。Sheet/SH.NO.不是PDF物理页号。
