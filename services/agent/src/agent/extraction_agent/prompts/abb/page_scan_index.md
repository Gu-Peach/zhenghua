# ABB Stage 2：整页连接读取（1.3.0）

只读本次来源图，输出注入的AbbScanResponse JSON。按图面从左到右、从上到下覆盖全部区域，示例中的设备、编号和条数不限制当前页。

## 读取顺序

1. 找放线小圆点（通常为空心小圆）。大空心圆是实际端子，实心黑点是连接点，蓝斜杠自身不作为ABB放线标记。无编号小圆点同样提取。图中明确的无圈断路器对外连接也保留：两端可见，或有实际导线出页地址；不把所有无标记柜内线都纳入。
2. 从同一放线段沿导线向两侧找最近实际端点，遇大端子、设备针脚或标有电位的母线/母排接点停止。沿连续导线和实际连接点走；无连接点的交叉不串接，不穿过断路器、端子或母排模块寻找更远设备。
3. 确认每端所属元件/排号，再读该端真实针脚。terminal填写完整设备/排号与端子，如Q3:1、X1:4；母线只标L1/N时保留原文。共用排号适用于同排接点，端子数字不能升格成另一个排号。不能把小圆点编号、跨页地址或附近其他线路数字当端子。未标出的针脚为空；不为凑两端虚构端子。
4. 根据同段箭头、来源/去向引用和可见接线确定方向。母线供电到设备输入；本页接收的跨页线标endpoint_role=receiver，不再作为本页发出连接。没有明确箭头时按可见路径判断，方向仍不明则unknown并记录uncertainties，不根据编号大小或上下位置强制定向。
5. 端点确定后读取本段起点侧、终点侧小圆点旁的原始数字，分别填start_marker_number、end_marker_number。无编号/不可读填null；数字可见但两侧均看不清时另填marker_numbers_unreadable=true，避免被当成无编号回退。同一直接段的两处标记只输出一条；即使编号不同，也先按实际路径配对，保留两侧读数，不按编号合并或拆开连接。经过大端子后的编号属于下一段。

## 编号与字段

line_number一律留null，由程序生成：优先起点侧标记数字，其次终点侧；两侧不同取起点侧并保留两者证据。没有标记数字时用本段完整实际端子标识，优先起点，其次终点。选定值直接拼来源图框Sheet，无分隔符；数字原文保留前导零。Sheet不可确认则原理号为空，不用PDF物理页、Cont、电位名或引用地址代替。

location是位置，device是元件，terminal_board是实际排号/接口，terminal是完整实际端子；它们按各自标注读取。母排模块的L1与断路器的1是不同端点，即使设备代号相同也按所在符号区分。signal_name是本段可见电位名称，与编号分开。wire_number未知为空，color始终为空。

## 跨页与坐标

只有当前导线直接连接的出页引用写references。/241.1A表示Sheet241、数字列1、字母行A，保留raw；地址不是标记编号或端子。辅助触点旁的关联位置索引不作为导线跨页。目标功能未知留空，不从源电位猜功能。图中两端可见则填start/end；需目标图时只保留来源start与references，end=null，交给内部补全。

可见端子的terminal_coordinates取实际针脚/端子或母线分支接点中心，以整图左上为原点，x/y分别除以整图宽高，使用当前PDF物理页。不要标小圆点、文字或箭头；位置不清为空。

## 电流与证据

明确、单一且属于本段设备的电流可读取，并保留current_basis与只包含电流标注的current_source_text，例如“100A”。范围电流不取上下限，SET系数不计算，不从电压/功率推算，也不把下游负载电流套给上游连接；N/PE/控制线无直接证据为空。不要把整块含600V等信息的文字混作电流证据。

扫描应覆盖本页全部适用放线段。无法确认的区域用uncertainties说明可见缺口，不复制示例连接到未看清的区域。红框、红箭头、中文教学批注不是业务字段；不使用外部表补值。只输出事实，复核状态由程序决定。
