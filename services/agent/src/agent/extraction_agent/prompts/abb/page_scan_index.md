# ABB Stage 2：小圆点放线扫描（1.2.1）

只读取当前图片和页面上下文，输出PageScanData JSON。

## 读取连接

1. 小圆点（图中通常是小空心圆）是放线标记，大空心圆是实际端子，实心黑点是导线连接点。从放线小圆点沿同一段导线向两侧找实际端点；大端子、设备针脚和标有L1/L2/L3/N的母线接点都可以是端点。母线直接到断路器输入端的段也要提取，不能因母线端没有X排号或设备针脚数字而漏掉。遇到实际端点即停止，不穿过端子或设备继续追下游；小圆点本身不是端子。
2. 同一直接连接段可能在两端各画一个小圆圈，旁边数字通常相同；这是同一条连接，只输出一个connection。不能按两个圆圈输出两条，也不能仅因编号相同跨过大端子或设备合并不同段。没有编号的小圆圈也照常提取。
3. 蓝斜杠不是本模板的放线标记；以用户确认的小圆圈确定放线段，不再因为同段有蓝斜杠就一律排除。仅有大圆圈不能证明存在放线标记。保留图中明确的无圈断路器对外出线，如Q3的2/4/6、Q4的2/4/6/8，不能把所有柜内线都作为这一例外。
4. 根据同段箭头及实际端子位置确定方向，只输出本页发出的连接，接收端不重复输出。无箭头时按实际接线判断；编号大小或是否有编号不决定方向。分支分别记录，同一连接的两个小圆圈放在同一unit的一条connection中。

母线供电段按母线→设备输入端记录。例如Sheet205上标记224的一对小圆点对应L1→Q3:1，只输出一条；225对应L2→Q3:3，226对应L3→Q3:5。Q5、Q4的输入段同样读取；Q6/Q7等上方有母排模块时，读取该模块可见的L1/L2/L3接点到下方断路器1/3/5端，不跳过模块追到更远的母线。

## 原理号与字段

- line_number=放线小圆圈旁数字直接拼来源图框Sheet，保留数字原文，不加加号、斜杠、连字符或空格。例如标记552、Sheet281→552281；标记552、Sheet208→552208。同段两处552仍只生成一条552281。
- 原理号是组合生成的值，不要求图上印出完整line_number。224与Sheet205生成224205；不得漏掉标记编号而统一改用Q3:1205，也不能把另一段的编号沿整条线路套用。两端相同编号只取一次。
- 无标记数字但有实际端子时，用完整端子标识直接拼来源Sheet。Q3的2端、Sheet205→Q3:2205；X1的1端、Sheet205→X1:1205。优先采用起点的完整设备/端子排端子标识；起点只有L1/N等母线电位时用本段可读的另一端实际端子。数字和完整实际端子都无法确认时line_number=null。只对确实无编号的段回退：Sheet205的N→X1:1小圆点旁有564，仍应生成564205。
- 回退端子要带实际排号/设备号，不能只拼裸数字；不把电位名Q4 L1、线径1015、规格10,00、LINK或600V当作小圆圈编号。图中两个小圈编号不一致时检查是否属于不同段，仍无法确认则留空复核。
- drawing_function读取图框功能代码并去掉=，drawing_page_number读取Sheet，Cont只是续页。PDF物理页号只来自上下文，不拿来拼原理号。
- location、device、terminal_board分开保存实际位置、元件和排号，terminal使用图中完整端子身份，对齐公共线表格式：排号X1旁的1填X1:1，设备-Q3旁的1填Q3:1；不要只填裸数字，不重复拼成Q3:Q3:1。大圆圈附近共用的-X1适用于同排11/12/13，结果是X1:11、X1:12、X1:13，不能把端子数字11当成排号X11。带编号的小圆点501不是端子501，而是该段原理号的数字部分。
- 母线端明确标注L1/L2/L3/N时，terminal保留该标注，坐标取该线分支的实际母线接点；不要虚构母线设备或针脚。所属母排模块的device/location按图保留。没有针脚/电位标识的接点terminal为空。++作为所属范围保存在part。
- wire_number是电缆编号，不是放线标记数字，不由模型分配。未知字段为空，不从外部表补齐；红框/中文教学标注不是业务值。
- 电流保留ABB现有证据约束：必须有直接、单一明确电流及原文依据，范围90–225A、10–25A不取上下限，不用SET系数计算。电压、N/PE/控制线不套电流，无依据时current/current_basis/current_source_text均为空。

## 跨页

/241.1A表示Sheet241、网格数字列1、字母行A，/289.3B表示Sheet289、列3、行B。保留raw，target_drawing_page填Sheet、target_column填数字列，行字母保留在raw/reason；这些都不是端子号。

只有与当前导线直接相连的出页引用写入references。/205.2D、/286.1A这类地址不是小圆点编号，不能生成205.2D281或286.1A281；跨页补全保留来源页已生成的原理号。辅助触点旁的/289.3B等关联位置索引不能仅凭地址格式生成跨页导线。=LV11-Q4 L1是匹配电位身份，不证明目标功能也是LV11；目标功能未知留空，由图册索引解析。

本页两端可读时填start/end；需要目标图时保留本页start，end=null、is_cross_page=cross_page、status=needs_reference，交给Stage 2内部补全。不按引用或常识猜终点。

Few-shot中部分案例只示范标题指定的连接，不是整页穷举。真实任务扫描整页全部符合规则的连接。

## 端子图片坐标

每个可见start/end填写terminal_coordinates={"x":0.2,"y":0.5,"pdf_page_number":1}，记录实际端子符号或连接点中心。以整张图片左上角为(0,0)，向右x、向下y增大，分别除以整图宽高归一化到0到1；等比例缩放不改变归一化位置。不能填放线标记、文字或箭头坐标，不按编号或外部表推算。端子未知或无法定位时为null。

初扫同页可见两端使用当前输入图片的PDF物理页号；跨页end仍为null。内部补全仅读取目标实际端子坐标，使用目标图PDF物理页，保留来源起点坐标。Sheet/SH.NO.不是PDF物理页号。

## 交给内部补全的事实

按放线标记找到端点后，读取同一导线或箭头旁的signal_name（可见信号/电位名），与line_number分开；无标注为null，不根据功能常识生成。来源起点、整图坐标、原理号和引用保存在state。跨页end=null，references保留目标业务页、列及raw中的字母行；不要提前猜目标端子。后续节点只看目标局部图，通过来源业务页回指、signal_name、原理号与references匹配这一条连接。
