## 2026-10-14：2.0.2 本地放线标记定位修订

- 初扫顺序明确为先定位导线斜杠标记，再从标记沿两侧寻找最近端子或跨页箭头，最后根据同段箭头判断端子角色。
- 原理号和端子文字只用于读取/匹配，不作为搜索起点；无标记的相邻连接不代替当前放线段。

- 本地Profile版本仍为2.0.2；运行时按修改后的资源内容重新计算Profile/Prompt checksum。未发布远端包，不改变已冻结的运行。
