## 坐标与资源

端点的`terminal_coordinates`为{x,y,pdf_page_number}：整张原图左上角为原点，x/y在0～1之间，点位表示实际端子符号中心。跨页起终点分别绑定来源/目标图片物理页，未知为null；手工样例坐标用于定位示例，仍待用户实际模型验证。最终记录为`start_terminal_coordinates`/`end_terminal_coordinates`，本地XLSX追加两列。
