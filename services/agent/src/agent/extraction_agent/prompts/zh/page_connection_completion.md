# Stage 2内部节点：定向连接补全（ZH 2.2.1）

本次只提供一张目标视图和task_context。视图可能是整页，也可能是程序按引用列裁出的全高度局部图；image_view存在时仅标记局部图模式、列号及input_image坐标空间，图像尺寸和原图裁剪框由程序保留。source_page与target_page分别标识来源/目标业务工作区、业务页及Object Loc；pdf_page_number用于图片与坐标绑定。来源端子、坐标和方向已由工作流保存在state，本输入仅带来源元件元数据source_component及匹配线路所需的原理号、信号名、引用、电流。本节点只读取该任务的目标端点。

## 读取顺序

1. **匹配对应线路。** 在目标图先找指向source_page业务工作区/页码的回指，再核对signal_name及同一线上的原理号。references给的是目标地址，目标图回指给的是来源地址，两者不能互换。002C0600、N、PE等可在同页重复，不能仅凭同号或相邻位置选线；保留信号名中区分回路的部分，例如FC11_N与LCM_FC50_N是不同线路。回指可在任意边，箭头也可朝外，不重新交换任务起终点。references.source_index_raw只表示目标地址已由来源页PDF原文核对，不替代目标图的线路匹配。对象位置文字有冲突时，若来源业务页和信号仍能唯一对应，则保留可见依据并在uncertainties说明冲突；不能改接另一条同号N线。不能唯一匹配时end=null并说明原因。
2. **沿线找到实际接点。** 从对应回指箭头沿导线向页内找最近实际端子符号/接点，遇到即停止，不穿过端子追到更远的断路器或PLC，也不把箭头旁的线路名称当成端子。
3. **分别读接口与针脚，再组合。** 先读该接点所属的实际接口/端子排，如X21、X2、XD21；再读紧贴这个接点的针脚数字或字母，保留标点、位数和字母。terminal_board填接口，terminal填完整接口:针脚。例如X21旁的5为X21:5，X2旁的9为X2:9；N_230、HTR_L等较长功能文字只帮助识别线路，不代替接点旁的5或9。不能根据来源端子编号填目标编号，也不把接口X2重复拼成X2:X2。只读到接口而未读到针脚时，保留接口、terminal=null并复核。图中直接标N-BAR/PE-BAR时，terminal按该原文填写，不套用相邻XD10前缀。terminal_code仅保存独立接口标识，没有则null；terminal_strip留null，由程序映射。
4. **读取目标接点坐标。** end.terminal_coordinates是刚找到的目标端子符号中心在本次实际输入图片上的归一化x/y（0到1，左上角为原点），使用目标PDF物理页。存在image_view时只返回当前局部图坐标，不自行添加偏移或换算整页，程序统一映射回原图。示例按其各自输入图片读取坐标，未提供image_view的示例为整页。不是箭头、文字或功能描述的位置，无法定位则null。

裁剪仅提供候选区域，不代表该区域一定有匹配线路。若回指、沿线接点或针脚不在视图中，或者导线离开左右裁剪边界后无法追踪，报告uncertainties（field=end，detail说明缺少的图像证据），未知字段为空；不把相邻线路当成目标。目标页Object Loc可使用target_page中已知的元数据。

## 元件和电流

终点元件按“任务对应出页引用对象→目标接点附近/所属框体元件→目标页Object Loc”读取，填end.device，end.location保存所属对象位置。常见元件为+01F...，附近同时出现对象位置和器件代号时取对象位置；接口排号、原理号、功能文字、页列号不填元件列。name只读可见元件描述。

目标图对应线路回指中的+对象属于来源元件，可以通过输出source_component(device/location/basis)补充来源元件元数据；任务中的source_component是已存元件，不是目标元件。没有新依据则输出source_component=null。来源端子、坐标、原理号、方向与已有电流由工作流保持，不返回完整start。

来源已有current时输出current=null表示保留。来源为空且目标明确给出本连接电流时，可在端点确定后独立沿同一相线查对应断路器，不改变端点/坐标。优先Ir，其次明确In/Ie；Ie:(0.7-1)*160A直接取160A，basis=Ie并保存完整原文，不计算系数、不改取Set或相邻回路值。必须带A/mA/kA单位。N、PE、控制、通信、光纤为空；不取漏电动作值、分断能力、Ii瞬时值、熔断器额定值、无唯一标注数值的范围，不从电压/功率推算。电流值、依据字段、原文证据不能同时给出时三项全null。

只输出符合CrossPageCompletionData JSON Schema的JSON。每次必须明确给出end（可为null），并用source_note或uncertainties记录匹配依据/不能确认的原因；不能返回{}、只给task_id或用空数组表示已经处理。没有找到也应明确回答，不编造端子。只补当前任务，不扫描整页或创建其他连接；正常来源回指是匹配依据，不继续递归跳页。
