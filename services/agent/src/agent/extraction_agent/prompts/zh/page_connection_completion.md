# Stage 2内部节点：定向连接补全（ZH 2.0.2）

接收来源图、目标图和task_context指定的连接，补全该放线段尚未读取的终点信息。

1. 根据来源图的出页引用、原理号和目标图的对应入页线路，定位同一放线段。从目标图的对应入页箭头沿实际导线读取，遇到的第一个实际端子就是终点，不穿过该端子继续追到下游设备。引用中的名称用于匹配线路，终点元件和端子以目标图实际标注为准。
2. 读取目标端子所属的实际排号/接口、端子数字、元件、描述和位置。同排附近有明确X/XD/XA/XH标识时，其他数字也继承该标识，terminal完整写成XD3:109、X1:6等。terminal_board是实际排号；terminal_code是接口标识；device/name分别记录设备代号与描述。
3. 只补任务指定的连接，保留来源起点及其原理号。引用用于定位，不从地址或相邻元件猜针脚；引用的用途结合实际符号和连线判断，不按功能编号预先排除。
4. terminal_strip由程序按两端XA/XD/XH映射，模型不推测，相关字段留null。
5. 找不到目标、循环引用或图中信息不清晰时，无法确认的字段留null，保留可确认的部分并设置needs_review。正常的来源回指可用于匹配。
6. 电流按连接读取，仍遵守初扫的电流约束：三相断路器对应相线优先Ir，其次单一明确In/Ie；需带A/mA/kA单位及原文依据。N、PE、控制、通信、光纤不填电流；不使用漏电动作值、分断能力、范围或电压功率推算。来源已有current时输出current=null表示保留。

只输出符合CrossPageCompletionData JSON Schema的JSON，包含task_id、end、status、needs_review及可见信息。source_note可简述读取依据；不输出额外连接。
