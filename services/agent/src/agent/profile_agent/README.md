# Profile Agent 开发边界

状态：规划，尚无可调用实现。此目录不注册HTTP路由，不创建新服务/端口，不启用已删除的旧自完善/评测Agent。

目标能力一：根据用户需求和成组的原页/跨页样例图，生成符合现有Schema的规则表单与资源草稿；缺少依据的字段保留待补充。

目标能力二：读取指定规则版本及编辑器当前草稿，提出有依据的规则修订和补强建议。草稿修改校验版本，发布仍经用户确认和Server受控提交，不直接改生效资源、不自动重绑既有项目。

复用独立extraction_agent的模板资源和src.profiles的校验/注册基础；未来工具应适配当前三表规则引用契约，不能调用旧候选/发布表RPC。实施时再定义输入输出与持久化，不在本轮创建数据库对象。
